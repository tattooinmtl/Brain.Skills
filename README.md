# 🧠 Brain.Skills

A unified, high-performance library of AI-agent skills, memory protocols, and harnesses built exclusively in **Go** and **Rust**.

Plugs into every major AI agent (Claude Code, OpenAI Codex, Cursor, Gemini, Grok, Kimi, MiniMax, Hermes, Omni, NimAgent, and custom harnesses).

**Website, downloads and docs: https://tattooinmtl.github.io/Brain.Skills/**

![The Global Brain's 3D neural view](website/assets/brain-3d.jpg)

---

## 🏗️ Architecture: Go CLI + Rust Daemon

This project is built with **zero Node.js dependencies** and runs as pure native compiled binaries:

1. **Native Go Launcher & Installer (`skills.exe`)**:
   - **Full System Scanner**: Discovers all known agent configurations and all custom `.*` dot-directories in your user profile (`~`).
   - **Instant Zero-Copy Junctions**: Creates Windows directory junctions (no admin rights needed) and Unix symlinks so skills are shared live across all agents.
   - **Catalog Indexer**: High-speed recursive scanner that parses `skills/` and generates `skills.json` and `INDEX.md`.
   - **Update Manager**: Runs `git pull --ff-only` and keeps all junctions in sync.

2. **Native Rust Memory & System Tray Daemon (`brain-system.exe`)**:
   - **Windows System Tray**: Native Windows taskbar icon with status and fast actions.
   - **Obsidian Memory Vault**: Live HTTP API and graph visualizer on `127.0.0.1:6789` serving `memory/`.
   - **Hermes Verifier Engine**: Automated background integrity audits and drift detection.

## 🚀 Quick Start

### Windows: two installers

Download from the [latest release](https://github.com/tattooinmtl/Brain.Skills/releases/latest) and double-click:

| Installer | Installs | Updates |
|---|---|---|
| **BrainSkills-Setup.exe** | The Global Brain tray app (3D neural view, wiki, Verifier Librarian, MCP server + Claude Code plugin) and the `skills` CLI | The tray checks GitHub every 6 h and shows **Update available**; one click updates |
| **Skills-Installer-Hub-Setup.exe** | The skills library, linked into every AI agent it finds (Claude Code, Codex, Cursor, Gemini, MiniMax, Omni…) | Tray menu, the **Skills Installer Hub** Start-menu item, or running the setup again |

Windows may show "Windows protected your PC" the first time: click **More info**, then **Run anyway**.
Both install per user into `%USERPROFILE%\.brain-skills` (no administrator), add themselves to
**Settings > Apps** for uninstalling, and download only the files that changed on update.
An existing memory vault at `C:\.skills\memory` is used as-is; nothing in it is ever deleted.

Or from PowerShell:

```powershell
irm https://raw.githubusercontent.com/tattooinmtl/Brain.Skills/main/install.ps1 | iex          # Brain.Skills app
irm https://raw.githubusercontent.com/tattooinmtl/Brain.Skills/main/install-skills.ps1 | iex   # Skills Installer Hub
```

### From a cloned repo (development)
```cmd
.\bin\skills.exe scan
.\bin\skills.exe install --auto
```

### macOS / Linux / Git-Bash
```bash
curl -fsSL https://raw.githubusercontent.com/tattooinmtl/Brain.Skills/main/bootstrap.sh | bash
```

## ⚡ CLI Commands (`skills.exe`)

| Command | Behavior |
|---|---|
| `skills scan` | Scans user home (`~`) for all agent folders and custom dot-directories |
| `skills install` | Interactive selector to configure target agents via directory junctions |
| `skills install --auto` | Automatically links skills to all detected default agents |
| `skills install --all` | Links skills to all detected agents and harnesses |
| `skills install --agents claude,cursor,codex` | Links skills to specific comma-separated agents |
| `skills sync` | Recursively indexes `skills/` and regenerates `skills.json` + `INDEX.md` |
| `skills update` | Runs `git pull --ff-only`, resyncs catalog, and validates junctions |
| `skills brain status` | Checks if the Rust memory daemon is active on `127.0.0.1:6789` |
| `skills brain start` | Launches the background Rust tray daemon |
| `skills brain verify` | Runs a memory vault verification sweep |

## 🛠️ Building From Source

Prerequisites: **Go 1.22+** and **Rust (cargo) 1.80+**. (No Node.js needed!)

```powershell
powershell -ExecutionPolicy Bypass -File installer\build-release.ps1
```

builds `bin\brain-system.exe`, `bin\skills.exe` and both setups in `dist\`.
Installed copies update from `main`, so commit the `bin\` binaries; attach the
`dist\` setups to a GitHub release. The setups always fetch the newest
`install.ps1` / `install-skills.ps1` from `main`, so they rarely need rebuilding.

How updates work: the installers and the tray read GitHub's file tree for the
latest commit. Every file there carries its git blob hash, so an update compares
hashes and downloads only what changed, verifying each file. There are no
manifests to keep in sync.

See [brain-system/README.md](brain-system/README.md) for the brain itself.

## 🔒 Security Notes

- **Sandboxed Local HTTP Server**: The Rust daemon binds strictly to `127.0.0.1:6789`, enforces strict CORS, and restricts `/api/note?path=` to the vault path.
- **Opt-in Startup**: Windows startup (`HKCU\...\Run`) is strictly opt-in via `skills.exe brain install-startup`.
- **Zero-Copy Junctions**: Uses Windows filesystem directory junctions without modifying operating system files or requiring administrator elevation.
