# Full-Stack App Developer

Skill integral para construir aplicaciones de producción completas, desde la concepción hasta el despliegue.

## Capacidades Principales

- **Desarrollo Backend**: APIs RESTful, GraphQL, microservicios, funciones serverless
- **Desarrollo Frontend**: React, Vue, Angular, Svelte, Next.js, Nuxt, diseño responsivo
- **Diseño de Bases de Datos**: SQL (PostgreSQL, MySQL), NoSQL (MongoDB, Redis), patrones ORM
- **Diseño UI/UX**: Interfaces modernas, accesibilidad, layouts responsivos, sistemas de diseño
- **Lógica de Negocio**: Diseño orientado al dominio, gestión de estado, estrategias de caché
- **Integración con IA**: APIs de LLM, modelos de machine learning, funcionalidades impulsadas por IA
- **Autenticación**: JWT, OAuth2, SSO, gestión de sesiones, mejores prácticas de seguridad
- **DevOps**: CI/CD, contenedorización (Docker), despliegue en nube (AWS, GCP, Azure)
- **Testing**: Tests unitarios, tests de integración, tests E2E, enfoques TDD

## Flujo de Trabajo de Desarrollo

### 1. Análisis de Requisitos
- Clarificar el propósito de la aplicación y usuarios objetivo
- Identificar features core y alcance MVP
- Definir preferencias de stack tecnológico
- Establecer requisitos de rendimiento y escalabilidad

### 2. Diseño de Arquitectura
- Diseñar arquitectura del sistema (monolito vs microservicios)
- Definir contratos de API y modelos de datos
- Elegir patrones apropiados (MVC, arquitectura limpia, etc.)
- Planificar medidas de seguridad y escalabilidad

### 3. Desarrollo Backend
```
Prioridad: API First → Base de Datos → Lógica de Negocio → Auth → Optimización
```

### 4. Desarrollo Frontend
```
Prioridad: Componentes Core → Páginas → Gestión de Estado → Estilos → Detalles
```

### 5. Integración y Testing
- Conectar frontend con APIs del backend
- Implementar manejo de errores y estados de carga
- Agregar testing comprehensivo
- Optimización de rendimiento

### 6. Despliegue
- Contenedorizar aplicación (Docker)
- Configurar pipelines CI/CD
- Desplegar a plataforma en nube
- Configurar monitoreo y logging

## Stack Tecnológico Recomendado

### Frontend

- **Estilos**: Tailwind CSS, CSS Modules, Styled Components

### Backend

### Base de Datos
- **Relacional**: PostgreSQL, MySQL
- **NoSQL**: MongoDB, Redis, DynamoDB
- **ORM**: Prisma, SQLAlchemy, TypeORM

### Cloud y DevOps
- **Contenedores**: Docker, Kubernetes
- **Nube**: AWS, GCP, Azure, Vercel, Netlify
- **CI/CD**: GitHub Actions, GitLab CI

## Estándares de Calidad de Código

1. **Seguridad de Tipos**: Usar TypeScript/Flow para type safety
2. **Código Limpio**: Seguir principios SOLID, DRY, nomenclatura significativa
3. **Documentación**: Comentarios en código, README, documentación de API
4. **Testing**: Cobertura mínima del 80% para paths críticos
5. **Seguridad**: Validación de input, sanitización, defaults seguros

## Patrones de Manejo de Errores

```javascript
// Respuesta de error estandarizada de API
{
  success: false,
  error: {
    code: "VALIDATION_ERROR",
    message: "Datos de input inválidos",
    details: [...]
  }
}

// Patrón de error boundary en frontend
try {
  await fetchData();
} catch (error) {
  if (error.code === "NETWORK_ERROR") {
    showRetryDialog();
  }
}
```

## Checklist de Seguridad

- [ ] Validación de input en todos los endpoints
- [ ] Prevención de inyección SQL
- [ ] Protección XSS (CSP, sanitización)
- [ ] Tokens CSRF para operaciones que cambian estado
- [ ] Rate limiting en endpoints públicos
- [ ] Headers seguros (Helmet.js)
- [ ] Variables de entorno para secrets
- [ ] HTTPS solo en producción
- [ ] Logging de auditoría para operaciones sensibles

## Optimización de Rendimiento

1. **Frontend**
   - Code splitting y lazy loading
   - Optimización de imágenes (WebP, lazy load)
   - Memoización y virtualización
   - CDN para assets estáticos

2. **Backend**
   - Optimización de queries de base de datos (índices)
   - Caché (Redis, CDN)
   - Connection pooling
   - Procesamiento async para tareas pesadas

3. **General**
   - Compresión Gzip/Brotli
   - Soporte HTTP/2
   - Monitoreo y alertas
