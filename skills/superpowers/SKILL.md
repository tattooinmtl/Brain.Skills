# Superpowers Engineering Suite

The Superpowers framework provides disciplined, repeatable workflows for complex software development and system architecture.

## Included Core Skills

The Superpowers suite includes the following specialized skills:

1. **`using-superpowers`**: Establishes skill invocation protocols before taking actions.
2. **`brainstorming`**: Interactive exploration and design refinement before committing to code.
3. **`writing-plans`**: Producing structured, phased implementation roadmaps with explicit checkpoints.
4. **`executing-plans`**: Executing plans step-by-step with progressive verification.
5. **`subagent-driven-development`**: Dispatching focused subagents for modular tasks.
6. **`systematic-debugging`**: Root-cause analysis and reproducible hypothesis testing before fixing bugs.
7. **`test-driven-development`**: Writing failing unit/integration tests before writing implementation code.
8. **`verification-before-completion`**: Comprehensive evidence-based validation before concluding any task.
9. **`requesting-code-review` & `receiving-code-review`**: High-standard automated peer review workflows.
10. **`using-git-worktrees`**: Isolated parallel branch workflows.
11. **`finishing-a-development-branch`**: Clean integration and merge verification.
12. **`writing-skills`**: Meta-skill for creating and refining new agent skills.

## Core Rules

- **Process Before Implementation**: Never jump into code before understanding requirements and having a clear plan.
- **Verification is Mandatory**: Every change must be verified with tests, compiler checks, or runtime inspection before claiming completion.
- **Root Cause First**: Do not apply superficial band-aids without identifying the underlying defect.
