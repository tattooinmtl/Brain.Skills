# Source Notes and Limitations

- The marketplace page is a JavaScript application and did not expose the complete skill file tree through static HTML in this runtime.
- Direct ZIP download from GitHub/codeload was unavailable from the execution container.
- This bundle contains compact skill folders with SKILL.md, agents/openai.yaml, README.md, and upstream links. It is not a byte-for-byte clone of every nested upstream file.

This combined skill is built from the compact bundle created in the previous step. For exact upstream nested files, use the upstream repository links listed in `minimax-skill-catalog.md` when online access is available.
