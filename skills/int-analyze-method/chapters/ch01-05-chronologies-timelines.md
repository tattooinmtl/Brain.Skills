# 1.5 — 大事记表与时间表法（Chronologies and Timelines）

**范式归属**：范式 Ⅰ：实证主义/经验描述范式
**方法类别**：第一类 分解与可视化
**编号**：1.5

## Core Idea
将事件按发生先后系统排列，核心功能不在"发现"而在"排列"——通过时间序化使分析员识别联系、模式、趋势与异常。最关键的洞察：时间表上的已知事件能引导分析员**假设尚未知晓的事件存在**，进而寻找被遗漏事件的指标。

## Framework / Mental Model
- **大事记表 + 时间表双工具**：表格（事件按序列排列）+ 图解（加入时刻与间隔）
  - When to use: 需理解事件时间和顺序、确定关键事件及其间隔、识别模式变化或发现数据空白时
  - How: 列事件→审查间隔与空白→多层级追踪同时发生事件→总结性图表
- **多层级时间表（Multiple-level Timelines）**：跟踪同时发生并可能互相影响的事件
  - When to use: 涉及多个行为体或多个并行进程时
  - How: 多条平行线显示各行为体活动，标注汇聚点

## Key Concepts
- **大事记表（Chronology）**：按发生先后顺序排列事件或活动的表格
- **时间表（Timeline）**：加入时刻和各事件间时间间隔的图解描述
- **指标性事件**：已知事件提示其他尚未知晓事件确实发生过
- **时间空白（Temporal Gap）**：两个关键事件之间异常漫长的间隔，可能藏有遗漏数据
- **多信息维度标注**：线之上描述事实，线之下进行分析或评论

## 操作步骤 (Procedure)
1. 确保相关信息按日期或发生先后顺序列出，引用数据资料恰当。
2. 通过提问审查大事记表/时间表：关键事件间隔多长？延迟原因？有否可填补空白的被遗漏数据？是否忽视了相关联信息？事件发生比预想快或看似不相关时，是否有多份时间表？时间表是否列出导致结果的所有关键事件？分析员/关键参与者何时获知信息？信息/情报空白是什么？某些时间点目标对象是否更易被搜集或受应对措施影响？时间表之外有什么事件可能影响了该活动？
3. 准备时间表时采用横向或纵向方式，沿线按序列出数据资料大意。充分利用线两侧空白标注重要分析点——线上描述事实，线下分析评论。可对比不同团体活动，或在线上下侧安排不同信息维度。行为体多时用多条线显示它们如何并在何处汇聚。
4. 从数据材料中寻找人员、地点、组织或其他活动的联系或模式。确定空白或不清楚的时间段，考虑证据缺失的潜在影响。准备总结性图表，按时间顺序详细标注关键事件和关键分析点。

## Worked Example
**示意**：跟踪某国导弹试射准备。时间表显示 T-90 天零部件采购、T-60 天设备转运、T-45 天（空白）、T-30 天发射架搭建、T-7 天人员集结。T-45 至 T-30 之间的空白提示可能有未捕捉到的燃料加注作业——分析员据此推断应启动遥感监测，果然在 T-22 天捕获到液罐车活动，弥补了空白。

## 适用场景 (When to Use)
- **何时使用**: 当需要理解相关事件发生的时间和顺序、确定关键事件及其时间间隔、识别模式变化或发现数据空白时
- **适合的问题类型**: 涉及序列事件的情报问题——武器系统开发、恐怖袭击准备、军事行动过程、政策演变等
- **团队还是个人**: 个人或团队均可
- **预期产出**: 按时间顺序排列的事件列表或图解，标注关键事件、时间间隔、分析点以及数据空白

## 对抗的认知偏见 / 核心价值
作为范式 Ⅰ 实证方法，大事记表填补的分析盲点是**时间维度的失明**——分析员倾向孤立地看待事件而忽视时序关系和时间空白。它通过强制按时间排列信息，让"事件间不该有的间隔"显现出来，引导分析员主动寻找被遗漏的中间事件。这是实证主义"让事实说话"的典型应用：通过严谨的数据组织而非主观推断来发现线索。

## 与其他方法的关系
该方法是一种基础性数据组织工具，可与其他结构化分析方法配合使用，为后续的因果分析、趋势预测和假设检验提供基础素材。

## Anti-patterns / 潜在缺陷
- **后此谬误（Post hoc ergo propter hoc）**：分析员可能错误地假定时间表中的后一事件是前一事件的结果——相关性不等于因果性，这是该方法最经典的陷阱
- **缺乏想象力的线性阅读**：如果分析员缺乏识别前后联系事件的想象力，该方法价值会大打折扣——只列出事件而看不出隐含关联

## Key Takeaways
1. 时间表的价值在"空白"而非"已知"
2. 已知事件提示未知事件——主动假设其存在
3. 多层级时间表能跟踪并行进程
4. 线上事实、线下分析，结构化标注
5. 后此谬误：时序相邻≠因果关系
