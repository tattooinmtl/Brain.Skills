# 2.6 — 形态分析法（Morphological Analysis）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第二类 观点生成
**编号**：2.6

## Core Idea
形态分析法是面对多维度、高度复杂且通常难以计量的问题时，**系统构建并研究所有可能关系**的方法。要旨：先确定一组变量，再研究这些变量的所有可能组合。通过生成包含所有可能结果的清单，分析人员能防止意外突发，对"高影响/低概率"发展与"噩梦情景"变得敏感。

## Framework / Mental Model
- **Zwicky 形态空间框架**：分解 → 强制关联
  - When to use: 可用信息少、意外概率高的不可计量复杂问题；识别威胁变化、危机可能方式、不明情形可能结果
  - How: 定关键参数维度 → 各维度分解状态 → 配对遍历形态空间 → 剔除不可能/不可行 → 聚焦值得关注的组合

## Key Concepts
- **分解**：确定关键参数或维度，是创造性方法通用原则之一。
- **强制关联**：对每对组成要素配对，思考其在"形态空间"中的关联。
- **形态空间**：所有维度状态的全组合空间，复杂案例可含成千上万对。
- **高影响/低概率**：通过穷举让此类发展与"噩梦情景"进入视野。
- **思维无序**：通过强制矩阵结构对抗的偏见。

## 操作步骤 (Procedure)
1. 确定问题的一组关键参数或维度。
2. 将每个维度分解成相应的形式、状态或价值。
3. 两维用矩阵呈现，三维用立方体；复杂情况可能需要多个关联矩阵。
4. 对每个组成要素配对，思考其在"形态空间"中与其他任一要素的关联。
5. 从可能性、可行性、有效性等角度研究每对组合。
6. 剔除不可能、不可行或不值得关注的组合（往往很大比例可快速剔除）。
7. 将注意力集中在有可能性或最值得关注的组合上。

## Worked Example
**示意**：识别恐怖组织可能的攻击方式。定3维度——目标类型（政府/民用/经济）、武器（爆炸/网络/生化）、渗透路径（陆/海/空/网络）。3×3×4 = 36种组合，剔除不可行后剩9种，其中"生化+经济+网络"是此前未被认真考虑的高影响情景。

## 适用场景 (When to Use)
- **何时使用**: 可用信息少、意外概率高的不可计量且复杂问题；识别威胁变化、危机可能方式、不明情形可能结果。通常课题初期使用。
- **适合的问题类型**: 多维度、高度复杂、不可量化的问题。
- **团队还是个人**: 团体，需有经验的指导人员辅导。
- **预期产出**: 一系列可能的情景，每个附指标与搜集需求。

## 对抗的认知偏见 / 核心价值
对抗**思维无序**与**意外突发**——通过分解+强制关联穷举形态空间，让此前未被想象的"高影响/低概率"组合进入分析视野，减少事件向未想到方向发展的概率。

## 与其他方法的关系
具体应用包括 **2.7 经典象限处理法™**、**多种情景生成法** 和 **象限假设生成法**；计算机版可参考瑞典形态学学会网站。

## Anti-patterns / 潜在缺陷
- 使用前需培训与练习。
- 复杂案例可有成千上万对组合，需计算机辅助。

## Key Takeaways
1. 分解 + 强制关联两原则
2. 穷举形态空间防意外
3. 大比例组合可快速剔除
4. 对高影响低概率敏感
5. 需培训与计算机辅助
