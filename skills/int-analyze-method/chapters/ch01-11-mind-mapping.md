# 1.11 — 思维图示法（Mind Mapping）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第一类 分解与可视化
**编号**：1.11

## Core Idea
以放射状结构呈现思维过程的图解方法——只有一个中心观点，所有其他观点围绕该中心呈放射状分布。最初作为收听简报或演讲时高效做笔记的手段，在情报分析领域被广泛用于头脑风暴、问题要素思考和关联分析。核心价值在于鼓励反思性提问：还有遗漏的类别或分支吗？

## Framework / Mental Model
- **放射状层次结构（Radial Hierarchy）**：中心主题 → 5-10 个主要观点 → 每个再细分 5-10 个子观点
  - When to use: 思考问题、制订计划或做决定时需要将一系列思考可视化；头脑风暴时发现遗漏类别；收听简报做笔记
  - How: 阐释焦点问题→列相关概念清单→首批 12 个概念分组→从最常见概念开始连线→选择链接短语描述关系→找交叉链接→重新配置完善
- **图片优于文字**：中心观点适合用图片而非文字显示，图片贯穿全图
  - When to use: 增强记忆和直觉理解时
  - How: 用图标、符号、彩图替代关键节点的文字标签

## Key Concepts
- **单一中心主题**：与概念图的多中心结构根本不同
- **放射状分支**：5-10 个主要观点围绕中心，每个再细分 5-10 个
- **反思性提问**：还有未考虑到的类别或"主干上的其他分支"吗？
- **链接短语**：选择"造成""影响""导致""致使""应……要求""有助于"等词描述关系——常是最困难的一步
- **交叉链接**：概念之间的非层级关系，揭示意想不到的关联

## 操作步骤 (Procedure)
1. 先阐释某个焦点问题，以此作为绘图起点。
2. 列出在某些方面与该焦点问题有关的概念清单。
3. 从首批 12 个左右的概念开始，以合乎一定逻辑的方式在图内空间进行分组。分组依据可以是共同特征，也可以基于它们是正在分析的问题的直接或间接原因。
4. 从最常见的概念开始，在相关概念之间连线。利用带箭头的连线显示关系的方向，箭头可以单向或同时指向两个方向。
5. 选择最恰当的词汇（如"造成""影响""导致""致使""应……要求""有助于"等）描述每种关系的性质。选择合适的链接短语往往是最困难的一步。
6. 在建立概念与焦点问题的所有链接的同时，寻找并输入概念之间的交叉链接。
7. 绘图过程中如果发现焦点问题已经不同于开始时，不必惊讶——这是好事。焦点问题的目的是让过程进行下去，而不是锁定主题。
8. 最后，对图进行适当的重新配置和完善，对其结构进行适当扩展。
9. 强烈建议使用绘图软件而非手工进行，在电脑屏幕上移动概念和链接更快捷。

## Worked Example
**示意**：分析"某国政权稳定性"。中心主题："政权稳定性"——围绕它画出 6 条主干：经济、军事、社会、外部、精英分裂、制度合法性。每条主干再细分——"军事"下：高级军官忠诚度、士兵士气、装备控制、私人武装；"精英分裂"下：派系数量、最近人事变动、家族矛盾。最后发现"军事"和"精英分裂"之间出现交叉链接——某派系正在拉拢警卫部队——这是图最有价值的发现。

## 适用场景 (When to Use)
- **何时使用**: 思考某个问题、制订计划或做决定时，需要将一系列思考可视化呈现；头脑风暴时发现遗漏类别或要素；收听简报或演讲时作为笔记工具
- **适合的问题类型**: 概念关系梳理、问题要素分析、创意生成、知识整合、学习笔记
- **团队还是个人**: 个人或团体均可。团体共同构建时，过程本身的价值常大于成品图的价值
- **预期产出**: 以单一中心主题为核心的放射状图解，展示相关概念及其关系

## 对抗的认知偏见 / 核心价值
作为范式 Ⅳ 协作工具，思维图示法对抗的核心偏见是**线性思维定势**——分析员习惯按因果链线性展开思考，忽视同时存在的多维平行因素。放射状结构强制让所有相关概念同时显形，暴露被线性叙事掩盖的并行要素。它还鼓励**反思性提问**——"主干上还有其他分支吗"——对抗不完整性厌恶（即满足于已找到的几个类别而停止探索）。

## 与其他方法的关系
思维图示法可用于直观呈现大量其他方法生成的结果，特别是各种类型的"头脑风暴"和"交叉影响分析法"生成的成果。

## Anti-patterns / 潜在缺陷
- **过度简化复杂关系**：思维图可能过于简化复杂关系。图的规模大小和复杂性应当适中，没必要把复杂关系的所有细微差别都表现出来。它只要提供一幅简略图，说明某个变量体系的总体结构即可

## Key Takeaways
1. 单一中心 + 放射状分支，与概念图根本不同
2. 图片优于文字，色彩增强记忆
3. 选择链接短语是最困难也是最有价值的一步
4. 焦点问题可变化——目的是驱动过程
5. 用软件而非手工，移动概念更快捷
