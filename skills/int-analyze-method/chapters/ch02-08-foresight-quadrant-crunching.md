# 2.8 — 远景象限处理法™（Foresight Quadrant Crunching™）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第二类 观点生成
**编号**：2.8

> **商标说明**：Foresight Quadrant Crunching™ 是伦道夫·弗森（Randolph Pherson）于 2013 年开发的商标化分析技术，作为开展多种情景分析的新方法模式。本方法名称须保留 ™ 符号。

## Core Idea
远景象限处理法™ 使用经典象限处理法™ 检验假定的最初方式，然后运用多种情景生成法，生成**大量范围广泛全面、互不相容的任何类型的未来情景或结果**，其中许多此前未被认真考虑。经典版侧重"避免意外突发"，远景版侧重**生成一系列全面的未来可能情景**。当出现某未来结果最有可能的强烈一致趋势时最为有效——它迫使分析人员考虑被共识忽视的替代未来。

## Framework / Mental Model
- **Pherson 多矩阵远景框架™**：经典版前4步 + 理所当然假定质疑 + 多2×2矩阵
  - When to use: 出现某未来最有可能的强烈一致趋势时；需生成5年或更长期未来情景时
  - How: 经典版前4步 → 显式质疑"理所当然"假定 → 多矩阵对多驱动力配对 → 每象限1–2情景 → 筛选挑战性未来 → 验证指标 → 定期报告

## Key Concepts
- **单一前景思维（Single-Outcome Thinking）**：本方法核心对抗的偏见，共识锁定某个未来时忽视替代。
- **理所当然假定（Taken-for-Granted Assumptions）**：绝大多数分析人员认为最不可能变化的假定，远景版关键区别即显式质疑之。
- **多矩阵配对**：使用多个2×2矩阵对多个驱动力每个可能组合配对，而非仅一个2×2。
- **互不相容的未来**：生成全面、彼此排斥的情景族，迫使考虑被共识边缘化的路径。

## 操作步骤 (Procedure)
1. 与经典版前4步相同：明确焦点问题，识别关键假定，选出两个正交维度，阐明每维度两端。
2. **关键区别**：阐明绝大多数分析人员认为是理所当然的、最不可能发生变化的假定。
3. 使用多个2×2矩阵对多个驱动力的每个可能组合进行配对（而非仅一个2×2）。
4. 为每个矩阵的每个象限形成1–2个情节。
5. 从所有生成的情景中，选出那些阐明尚未被考虑的、具有挑战性的未来。
6. 为每个情景生成并验证指标。
7. 定期就哪个情景看似正在形成及其原因进行报告。

## Worked Example
**示意**：预测叙利亚冲突未来5年。共识"阿萨德政权稳固"。团队显式质疑"理所当然"假定（俄支持不变、反对派已瓦解），用"外部支持"×"反对派凝聚"多矩阵生成8情景，浮现"俄撤资+新联盟"路径，附5项早期预警指标供持续监测。

## 适用场景 (When to Use)
- **何时使用**: 当出现某未来结果最有可能的强烈一致趋势时；需生成5年或更长期未来情景时，如预测叙利亚冲突在未来5年如何发展。
- **适合的问题类型**: 长期战略前瞻、复杂局势演变预测。
- **团队还是个人**: 团体，需经验丰富的指导人员。
- **预期产出**: 大量广泛的未来情景及其指标。

## 对抗的认知偏见 / 核心价值
核心对抗**单一前景思维**——当团队对某未来形成强烈共识时，替代未来被系统性忽视。远景版通过显式质疑"理所当然假定"+多矩阵穷举，强制考虑被共识边缘化的互不相容未来，让分析人员对广泛可能性做好准备并识别早期指标。

## 与其他方法的关系
与 **2.7 经典象限处理法™** 配对；是 **多种情景生成法** 的演变形式；三者（含 **2.6 形态分析法**）都是形态分析法的具体应用。

## Anti-patterns / 潜在缺陷
- 需要培训和经验丰富的指导。
- 生成的情景数量大，需要有效的筛查和优先排序机制。
