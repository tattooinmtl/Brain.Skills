# 3.6 — 指标验证因子法™（Indicators Validator™）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第三类 情景与指标
**编号**：3.6

## Core Idea
一种**评定指标诊断力**的商标化方法过程，由弗森联合有限责任公司（Pherson Associates, LLC）的伦道夫·弗森、格雷斯·斯卡伯卢、艾伦·施瓦茨和萨拉·毕比开发，首次发表于弗森《分析工具与方法手册》。当某个指标明确显示**只有一种情景或假设具备可能性而其他均不可能**时，该指标最具诊断力；通常指标价值有限，因它们常与多个结果吻合。本方法通过矩阵化评估每个指标在每个情景中的出现可能性，找出真正具识别力的指标。

## Framework / Mental Model
- **诊断力矩阵（Diagnostic Power Matrix）**：左列指标 × 顶行情景/假设，单元填该指标在该情景中出现的可能性（高/中/低 或概率值）。
  - When to use：已有指标清单但不确定哪些真有区分力；需优化搜集资源配置。
  - How：列情景 → 列指标 → 填矩阵 → 算诊断力 → 排序 → 聚焦高诊断力指标。
- **诊断力判据**：某指标在部分情景可能性高、在其他情景低 → 诊断力强；在所有情景可能性相似 → 诊断力弱。

## Key Concepts
- **诊断力（Diagnosticity）**：指标区分不同情景/假设的能力，是本方法的核心度量。
- **情景/假设集**：评估基础，通常 3–5 个定义良好的情景或假设。
- **可能性评分**：高/中/低 或概率值，由专家判定。
- **等级序列输出**：高诊断力指标按排序或按情景列出，指导搜集。
- **对抗虚假指标（false / non-diagnostic indicators）**：矩阵显式暴露那些看似相关实则与多情景吻合的指标，防止搜集资源被低诊断力信号占用。

## 操作步骤 (Procedure)
1. 确定需要区分的一组情景或假设（通常 3–5 个）。
2. 列出所有备选指标清单。
3. 制作矩阵：左列指标，顶行情景/假设。
4. 对每个指标，评估其在每个情景中出现的**可能性**（高/中/低 或概率值）。
5. **计算诊断力**：某些情景高、其他低 → 强；全部相似 → 弱。
6. 按诊断力排序，识别最具识别力的指标。
7. 将高诊断力指标按等级序列或按情景列出。
8. 用这些指标指导后续搜集工作。

## Worked Example
**示意**：区分 3 个情景——A 政权延续 / B 渐进改革 / C 突变崩溃。备选指标 10 个，矩阵评分后发现"高级将领公开表态效忠"在 A 高、B 中、C 低（诊断力强）；"油价波动"在三者皆高（诊断力弱）。最终筛选出 4 个高诊断力指标作为搜集重点，舍弃 3 个与多情景吻合的虚假指标。

## 适用场景 (When to Use)
- **何时使用**：已有指标清单但不确定哪些真正有区分力；需在多情景间做判断；优化搜集资源配置。
- **适合的问题类型**：有多个替代情景/假设且需识别关键区分指标的问题。
- **团队还是个人**：团体或个人均可。
- **预期产出**：按诊断力排序的指标清单，识别出最具识别力的指标。

## 对抗的认知偏见 / 核心价值
对抗**虚假指标**——分析人员常把"看起来相关"的信号误认为有预警价值，实际上这些信号与多个情景吻合，无法区分 rival hypotheses。矩阵化评估强制每个指标接受跨情景的诊断力检验，把低区分度的虚假指标暴露并剔除，使搜集资源聚焦于真正具识别力的观察点。这是对指标法（3.5）诊断力不足缺陷的直接、量化补足。

## 与其他方法的关系
是对指标法（3.5）的补充与升级；与所有情景方法（3.1–3.4）配对使用以优化指标选择；与竞争性假设分析法共享"诊断力"概念（证据区分假设的能力）。

## Anti-patterns / 潜在缺陷
- 需先有一组定义良好的情景/假设作为评估基础——否则矩阵无意义。
- 单元格的可能性评分仍依赖专家主观判断，引入新偏见。
- 过度依赖矩阵输出，忽略定性 context。

## Key Takeaways
- 商标化诊断力评估方法
- 矩阵化：指标 × 情景
- 高诊断力 = 区分能力强
- 对抗虚假指标
- 补足 3.5 诊断力不足
