# 4.4 — 诊断推理法（Diagnostic Reasoning）

**范式归属**：范式 Ⅰ：实证主义/经验描述范式
**方法类别**：第四类 假设生成与检验
**编号**：4.4
**创始人/来源**：源自医学诊断领域，在情报分析中改编应用

## Core Idea
将假设检验应用于评估新信息、新发展或新情报来源的轻量级方法。核心理念：面对任何重要新信息，分析人员不应仅从已有思维模型出发做直觉判断，而应主动思考"这条信息在所有看似合理的替代解释下意味着什么"。关键洞见——支持某个首要假设的许多信息，最终也会与替代假设一致；重要的不是信息是否"支持"主流观点，而是它是否具有"诊断价值"。

## Framework / Mental Model
- **诊断价值（Diagnostic Value）**：一条信息能否在不同替代判断间做出区分的能力。
  - When to use: 评估单项证据或单个情报来源时
  - How: 若信息对所有替代判断一致度均等 → 无诊断价值，忽略；若明显与某判断矛盾 → 剔除该判断
- **证伪优先**：寻找其他证据继续反驳（而非证实）剩下的替代判断。

## Key Concepts
- **首要假设**：分析人员直觉倾向的解释。
- **替代判断**：与新信息/新发展/新来源也可能一致的其他解释。
- **诊断价值**：信息在替代判断间区分的能力，而非支持能力。
- **暂时性判断**：基于证伪式思考得出的可修订结论。
- **对抗认知偏见**：经验跳跃——强制进行症状→疾病的系统性匹配，防止从"看到熟悉症状"直接跳到"确诊为某病"。

## 操作步骤 (Procedure)
1. 接到一条可能重要的信息，琢磨其蕴含内容（解释为何发生，还是预示将发生什么）。根据当前思维模型快速做直觉判断。
2. 定义焦点问题：首要假设是否有替代解释，并且也与新信息一致？除了首要假设，是否还有其他理由？
3. 单独或小团体头脑风暴，制定替代判断清单。
4. 针对每个替代判断提问："如果该替代判断是可靠的，那么我看到这条新信息的可能性有多大？"
5. 基于这些思考做出暂时性判断。对所有判断一致度均等 → 无诊断价值，忽略；明显矛盾 → 剔除相应判断。
6. 逐一进行这种模式思考，决定哪些需进一步关注、哪些可搁置。
7. 寻找其他证据继续反驳（而非证实）剩下的替代判断。

## Worked Example
新情报："X 国突然撤回驻 Y 国大使"。直觉判断："X 国即将对 Y 国采取军事行动"。替代判断：①外交抗议施压；②大使健康原因；③两国秘密谈判破裂；④常规轮换。逐条评估：若为常规轮换，看到突然撤回的可能性低；若为健康原因，通常会有官方解释。最终剔除②④，保留①③作为待验证判断。

## 适用场景 (When to Use)
- **何时使用**：评估某事物新发展的意义、某份新报告的重要性或新情报来源可靠性时；发现自己快速做出直觉判断时；正在寻找证据证实已有思维模型时。
- **适合的问题类型**：需实时评估新信息意义的各种情报分析任务。
- **团队还是个人**：个人和小团体均可。
- **预期产出**：对新信息诊断价值的评估结论，以及对替代判断的更新清单。

## 对抗的认知偏见 / 核心价值
- **经验跳跃**：强制症状→疾病的系统性匹配流程，防止凭经验直觉跳到结论。
- **证实偏见**：寻找反驳而非证实的证据，是证伪哲学在日常分析中的应用。
- 核心价值：作为 ACH 的轻量级日常版本，可高频嵌入日常工作流。

## 与其他方法的关系
是 **4.5 ACH** 和 **指标验证因子法™** 不可或缺的组成部分；作为批判性推理的基本形式，在情报分析领域应用广泛。比 ACH 更灵活、更轻量，用于评估单项证据；ACH 更综合、更深入，用于处理多项证据和完整问题。

## Anti-patterns / 潜在缺陷
- 需判断信息是否准确、是否具有欺骗性或故意误导性质。
- 可能出现没有哪个关键信息具有诊断力的情况，或所有相关信息都不够明确。

## Key Takeaways
- 诊断价值 ≠ 支持价值
- 信息在所有判断间均等一致 → 忽略
- 信息与某判断矛盾 → 剔除该判断
- 寻找反驳而非证实
- ACH 的轻量级日常版本

## Connects To
- **4.5 ACH**：诊断推理是 ACH 矩阵每格评估的底层思维操作。
- **指标验证因子法™**：诊断推理是其组成部分。
- **范式 Ⅰ 经验主义**：源自医学百年诊断实践，强调症状→疾病的经验映射。
