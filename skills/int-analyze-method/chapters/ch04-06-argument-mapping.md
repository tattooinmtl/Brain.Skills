# 4.6 — 论证图示法（Argument Mapping）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第四类 假设生成与检验
**编号**：4.6
**创始人/来源**：可追溯至 19 世纪初；约翰·亨利·威格摩尔（John Henry Wigmore）20 世纪初将其用于法律辩论

## Core Idea
对单个假设进行严格逻辑检验的视觉化方法。从一个假设或暂定分析判断出发，用**树形图**将主张和证据分开展示，帮助分解复杂问题，厘清结论背后的完整推理过程。论证图以起始结论为树根，向下分叉出关键原因、支持证据，最终追溯到最基础的假定。这个过程有助于明确逻辑中的关键假定和逻辑空白。

## Framework / Mental Model
- **三色论证树（Three-Color Argument Tree）**：现代论证图用颜色编码推理关系。
  - 🟢 绿色线条 = 支持关系（支持主要观点的原因 → 结论；支持原因的证据 → 原因）
  - 🔴 红色线条 = 反对关系（反证、反对意见、挑战）
  - 🟠 橙色线条 = 反辩关系（针对反对意见的回应）
  - When to use: 直觉判断后检验推理过程；撰写情报产品前确保论证质量；向他人阐明复杂推理时
  - How: 自顶向下构建——根结论 → 关键原因 → 证据 → 反证 → 反辩

## Key Concepts
- **起始结论（树根）**：一句话陈述的首要假设或分析判断。
- **关键原因**：支撑结论的主要理由。
- **支持证据**：支撑关键原因的具体数据/情报。
- **反证/反对意见**：与原因不符的证据，红色标示。
- **反辩（橙色）**：针对反对意见的回应——任何没有橙色标注的反对意见都说明论据存在缺陷。
- **对抗认知偏见**：逻辑谬误 / 隐藏前提——通过把整个推理链可视化，暴露隐藏假定、循环论证、逻辑跳跃。

## 操作步骤 (Procedure)
1. 在论证树图顶端写下首要假设（一句话陈述/判断/主张）。
2. 在起始方框下方画出一组方框，列举关键原因和关键反对理由。
3. 用绿色线条将支持主要观点主张的原因或其支持的结论连接起来。
4. 用绿色线条将支持关键原因的证据和该原因连接。提示：陈述原因后自问"是因为什么"，答案即为要寻找的证据。
5. 找出与原因不符的任何反证，用红色线条把反证及其反驳的理由联系起来。
6. 明确针对主要观点主张或关键结论的反对意见或挑战，用红色线条连接。
7. 明确支持反对意见或挑战的反证，用红色线条连接。
8. 如果存在反辩，用橙色线条标明。任何没有橙色线条标注的反对意见、挑战或反证，都说明论据中存在缺陷。
9. 评估论据的清晰性和完整性，确保所有红色标明的对立观点都有橙色标明的反辩。如果所有原因都可被反辩，论证就没有价值。

## Worked Example
结论："X 国将在 6 个月内进行核试验"。绿色支撑：①卫星显示新掘进活动；②采购高能炸药；③外交姿态突然强硬。红色反对：①历史间隔通常 ≥18 个月；②掘进也可能是常规矿场。橙色反辩：①卫星图像经信号情报交叉验证；②采购的炸药类型专用于武器。

## 适用场景 (When to Use)
- **何时使用**：直觉判断后，用论证图检验自己的推理过程；撰写情报产品前确保论证质量和完整性；需要向他人清晰阐明复杂推理时。
- **适合的问题类型**：涉及因果关系的复杂分析问题；需严格论证逻辑的情报评估。
- **团队还是个人**：个人和团队均可，协同使用效果更佳。
- **预期产出**：一份包含完整论证链的可视化图示，附有支持/反对证据及其逻辑关系。

## 对抗的认知偏见 / 核心价值
- **逻辑谬误**：可视化整个推理链，使隐藏的循环论证、诉诸权威、滑坡谬误暴露无遗。
- **隐藏前提**：把推理链追溯到最基础的假定，迫使分析人员明确那些"想当然"的预设。
- **因果混淆**：论证图是应对因果评估问题的绝佳工具，可帮助避免将相关关系误当做因果关系。
- 核心价值：是 ACH 之后的"显微镜"——深度检验单一假设的逻辑结构。

## 与其他方法的关系
是 **4.5 ACH** 合乎逻辑的后继步骤。两者可同时使用：**ACH 处理多种假设的全面筛选（广角镜），论证图示法聚焦筛选出的假设进行深度逻辑检验（显微镜）**。理想流程：ACH 从多假设中筛选出最站得住脚的一个 → 论证图示法严格检验该假设的论证结构。论证图也是应对**第五章因果评估问题**的绝佳工具。

## Anti-patterns / 潜在缺陷
- 具有相当难度，需要培训和实践才能正确使用并获得收益。
- 初次使用者有必要从有经验者那里获得帮助。
- 没有软件辅助时，在白板上贴便利贴替代方框也是可行方案。

## Key Takeaways
- 树形图可视化论证
- 绿色支持、红色反对、橙色反辩
- 无橙色的红色 = 论据缺陷
- 追溯到最基础假定
- ACH 的"显微镜"

## Connects To
- **4.5 ACH**：下游——ACH 筛选后的假设用论证图示法深度检验。
- **第五章 因果评估类**：帮助避免相关 vs 因果的混淆。
- **范式 Ⅲ 证伪主义**：红色反对/橙色反辩机制是证伪逻辑的可视化实现。
