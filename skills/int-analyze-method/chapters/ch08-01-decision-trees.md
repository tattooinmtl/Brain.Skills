# 8.1 — 决策树法（Decision Trees）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第八类 决策支持
**编号**：8.1

## Core Idea
将决策可视化为树形图——方块为决策点、圆圈为可能性节点、枝条为选项与结果。每条路径末端附概率乘积，使决策者一眼看清选项范围、概率与后果。新信息到来时用颜色标注已变化部分，让"什么变了、如何变"对外显化。

## Framework / Mental Model
- **选项链—事件链结构**：方块（决策）→ 枝条（行动选项）→ 圆圈（事件）→ 枝条（结果）→ 概率乘积。
  - When to use：需在多选项间权衡、或为对手决策建立启发式模型时
  - How：自方块出发逐层展开，每节点分配百分比（合计 100%），路径末端记录各百分比连乘积
- **路径概率法则**：所有路径百分比之和必须等于 100%——这是自检条件。

## Key Concepts
- **方块（决策节点）**：分析人员或行为体可选的行动。
- **圆圈（事件节点）**：超出决策者控制、带概率的结果。
- **路径概率**：自根到叶的连乘积——最有价值/最可能路径概率最高。
- **颜色标注增量**：新信息出现时高亮变化枝条，避免"无声更新"。
- **对手决策建模**：可绘制对手的决策树以预测其行为。

## 操作步骤 (Procedure)
1. 确定问题，在白板上画一个方块代表决策点。
2. 自方块引出若干线条，代表可采取的行动选项。
3. 在每条线末端：若仍有后续选项则画方块；若产生结果则画圆圈并引出可能性枝条。
4. 沿枝条递归展开，直到所有选项与结果被明确标示。
5. 为每个节点引出的枝条分配百分比（兄弟枝条合计 100%）。
6. 将每条根到叶路径上的百分比连乘，记于树形最右侧。
7. 校验：所有路径概率之和 = 100%。
8. 最高路径概率 = 最可能/最有价值的结果；最低 = 最不可能。

## Worked Example
决策："Y 国是否会响应制裁撤军？" 方块 → 两选项：强硬回应 / 妥协。强硬分支圆圈 → 公开对抗（60%）/ 暗中升级（40%）。妥协分支圆圈 → 完全撤军（20%）/ 部分撤军（80%）。两选项各 50%。路径概率：强硬公开 0.5×0.6=0.30、强硬暗中 0.5×0.4=0.20、妥协完全 0.5×0.2=0.10、妥协部分 0.5×0.8=0.40。决策者看到"妥协部分撤军"概率最高（0.40），预做对应准备。

## 适用场景 (When to Use)
- 通过明确对比选项辅助决策。
- 为决策主体或对手的决策过程建立启发式模型。
- 对一系列可能行动绘制多个竞争性假设。
- 需在多选项间做出权衡的决策问题与竞争态势分析。

## 对抗的认知偏见 / 核心价值
**思维无序 / 忽略概率分支**：人脑工作记忆无法同时持有所有分支与其概率。决策树把分支与概率外化为可审计的图，强制每一选项的概率被显式赋值，反制"只考虑最熟悉分支"的倾向。

## 与其他方法的关系
结构上类似关键路径分析与 PERT 图，但后两者只显示完成任务的行动顺序，不含概率；犯罪调查的时间表分析可视为事件发生后的"决策树"。

## Anti-patterns / 潜在缺陷
- 一棵详尽的决策树会制造"作者已想到所有选项"的错觉——未列入的选项往往最多。
- 质量取决于数据可靠性、选项完整性、概率赋值有效性。
- 概率多为主观估计，易受 anchoring 影响。

## Key Takeaways
- 可视化选项—事件—概率—后果的层级链。
- 兄弟枝条百分比合计 100%；路径概率连乘；总路径概率合计 100%。
- 新信息用颜色标注，使分析演进对外可见。
- 可对对手绘制以预测其决策。

## Connects To
- **8.2 决策矩阵法**：决策树按分支展开概率，决策矩阵按标准加权评分——前者处理事件不确定性，后者处理多标准偏好。
- **红队分析法 / 红帽分析法**：用决策树为对手决策建模。
- **关键路径 / PERT**：结构同源，但无概率维度。
