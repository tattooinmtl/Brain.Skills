# 2.5 — 交叉影响矩阵法（Cross-Impact Matrix）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第二类 观点生成
**编号**：2.5

## Core Idea
在"诸事皆有关联"的背景下，交叉影响矩阵法帮助分析人员系统检查每个要素如何影响所有其他看上去相关的要素。其核心价值在于揭示**原本认为简单而独立的变量，事实上却是相互关联的**。通过强制矩阵结构，对抗思维无序（mental shotgun），让所有变量间的关系假定被明确写出、可追溯、可辩护。

## Framework / Mental Model
- **n×n 对称矩阵 +/+/- 评估框架**：变量同时罗列在左列与顶行
  - When to use: 形势变化需了解因素间关联；稳定时识别扰动源；重大事件刚发生需评估影响
  - How: 头脑风暴出变量 → 建 n×n 矩阵 → 每对变量评 +/-（无重大影响留空）→ 关注被忽视或彼此增强的组合

## Key Concepts
- **不对称关系**：变量1对变量2的影响可能与变量2对变量1不同，每对需评估2次。
- **+/− 记录**：增强记"+"，减弱记"-"，无重大影响留空。
- **可辩护论证**：所有关系假定被显式记录，结论可沿前提路径追溯。
- **思维无序（Mental Shotgun）**：本方法对抗的偏见，强制结构化穷举。

## 操作步骤 (Procedure)
1. 召集对该课题各方面熟悉的团体。
2. 通过头脑风暴得出可能影响问题的变量或事件清单。
3. 制作矩阵，将变量同时罗列在左列和顶行。
4. 评估并记录每对变量关系：变量1会增强还是减弱变量2、3、4？用"+"或"-"记录，无重大影响留空。
5. 重点关注可能被忽视的重大相互影响，或可能彼此增强的变量组合。
6. 每对变量关系需评估2次（不对称性）。
7. 可在线协作，记录在维基网页。

## Worked Example
**示意**：分析某国货币危机。头脑风暴得6变量（油价、外资、外储、通胀、政局、制裁）。建6×6矩阵，评估发现"制裁→外储"为强负、"政局→外资"为强负，且"制裁+政局"彼此增强——单独看任一变量都低估了共振风险。

## 适用场景 (When to Use)
- **何时使用**: 形势不断变化需了解所有因素关联；稳定时识别可能打乱稳定的因素；重大事件刚发生需评估影响。
- **适合的问题类型**: 复杂、多变量相互作用的系统性问题。
- **团队还是个人**: 团体。
- **预期产出**: 一个填满 +/- 号的交叉影响矩阵，揭示变量间关系。

## 对抗的认知偏见 / 核心价值
对抗**思维无序（mental shotgun）**——分析人员面对多变量易跳跃式联想、遗漏隐含关联。矩阵强制穷举每对关系（含不对称方向），让"看似独立的变量实则关联"显形，所有论证可追溯辩护。

## 与其他方法的关系
通常在 **2.1 结构化头脑风暴** 之后使用；是 **复杂性管理程序法** 不可或缺的一部分；可在此基础上绘制思维图或概念图。

## Anti-patterns / 潜在缺陷
- 6变量即30种交叉影响，讨论极耗时间。
- 应根据了解到多少决定讨论深度，避免过度沉溺。

## Key Takeaways
1. 矩阵强制穷举变量关系
2. 关系不对称，每对评2次
3. +/− 显式化可辩护
4. 关注彼此增强的组合
5. 按已知程度决定深度

## Connects To
- **2.1 结构化头脑风暴**: 提供变量清单的上游方法。
- **复杂性管理程序法**: 矩阵是其核心组件。
- **范式 Ⅱ**: 量化/系统分析范式的代表。
