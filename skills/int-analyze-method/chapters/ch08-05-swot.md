# 8.5 — SWOT 分析法（SWOT Analysis）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第八类 决策支持
**编号**：8.5

## Core Idea
用 2×2 矩阵评估任何项目或行动计划的 **内部**优势/劣势与 **外部**机会/威胁。关键不是"列出四类东西"，而是**内外因 × 正负面**的结构化交叉：内部 S/W 与外部 O/T 匹配后才产生可操作策略。斯坦福研究所 1960s 开发，是商业与情报领域最著名、也最常被滥用的方法之一。

## Framework / Mental Model
- **2×2 结构矩阵**：
  - 内部 / 正面 = Strengths（优势）
  - 内部 / 负面 = Weaknesses（劣势）
  - 外部 / 正面 = Opportunities（机会）
  - 外部 / 负面 = Threats（威胁）
  - When to use：设定目标后需组织信息支持战略计划时
  - How：四象限列举 → 1-5 赋值 → 匹配转换（SO/ WO/ ST/ WT）→ 策略
- **匹配与转换（Matching & Converting）**：S×O = 用优势抓机会；W×O = 用机会补劣势；S×T = 用优势避威胁；W×T = 防御性收缩。

## Key Concepts
- **内部 vs 外部**：S/W 是组织自身属性；O/T 是环境特征。混淆内外是常见错误。
- **优势/劣势的对偶性**：强项在错误场景下即弱项（如"高效流程"在创意任务中是约束）。
- **TOWS 矩阵**：SWOT 的策略生成变体——把四象限交叉为 SO/WO/ST/WT 四类策略。
- **赋值排序**：每象限按 1-5 给项赋值，避免泛泛清单。
- **结构化版本 vs 退化版本**：⚠️ SWOT 最常见的误用是退化成"四类清单"而无匹配——这等于没做 SWOT。

## 操作步骤 (Procedure)
1. 定义目标（清晰、单一）。
2. 列出优势——内部资源、能力、专业领域强项。
3. 列出劣势——需要改进的资源限制或不足。
4. 列出机会——外部环境中有利于目标实现的因素或趋势。
5. 列出威胁——外部环境中会阻碍目标实现的因素。
6. 各项按重要性入象限，可按 1-5 赋值。
7. 通过四问确定策略：如何发挥优势？如何改进劣势？如何利用机会？如何减轻威胁？
8. 与"匹配与转换法"结合：S×O、W×O、S×T、W×T 交叉生成具体策略。

## Worked Example
评估某情报机构新设网络小组的战略定位。

| | 正面 | 负面 |
|---|---|---|
| **内部** | **S**：资深技术专家 2 名；机构授权明确 | **W**：预算有限；跨部门协调经验不足 |
| **外部** | **O**：盟国共享情报渠道新开；网络威胁事件上升（关注度红利） | **T**：法律审查趋严；私营部门薪酬竞争人才流失 |

匹配策略：S×O——用专家身份对接盟国渠道；W×O——借关注度红利争取预算补强；S×T——以授权明确性应对法律审查；W×T——以培训与职业路径对冲人才流失。

## 适用场景 (When to Use)
- 设定目标后，需搜集和组织信息支持战略计划。
- 战略计划、项目启动评估、竞争分析。
- 对外国对手或竞争者进行全面评估（外化为它的 SWOT）。
- 团队过程最佳，单人亦可。

## 对抗的认知偏见 / 核心价值
**单维战略思维**：默认只看己方优势或只看外部威胁。SWOT 强制内外因 × 正负面四维并行，把单维思考升级为结构化匹配。

## 与其他方法的关系
SWOT 的 O/T 象限与 **由表及里思考法** 的外部环境因素重叠。替代方法 **TOWS 矩阵** 将四象限交叉为多类替代策略。

## Anti-patterns / 潜在缺陷
- ⚠️ **最常见的误用：退化成四类清单**，不做匹配转换、不赋值排序——这等于没做 SWOT。
- 只专注单一目标，不衡量替代方案的成本收益。
- 可能过于简化，信息质量直接决定结果有效性。
- 内外因混淆（如把"市场需求"误列为优势）。

## Key Takeaways
- 2×2 = 内部/外部 × 正面/负面——结构是核心，不是清单。
- 匹配转换（SO/WO/ST/WT）才是策略生成器。
- 每象限赋值排序，避免泛泛列举。
- SWOT 是入口，TOWS 是策略产出。

## Connects To
- **由表及里思考法**：O/T 象限共享外部环境框架。
- **TOWS 矩阵**：SWOT 的策略生成延伸。
- **8.4 力场分析**：SWOT 偏战略评估；力场偏变革策略——可前后衔接。
