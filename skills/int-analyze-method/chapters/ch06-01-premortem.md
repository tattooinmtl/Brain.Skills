# 6.1 — 事前分析法（Premortem Analysis）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第六类 质疑分析
**编号**：6.1
**★ 核心方法 (原书结语推荐)**

## Core Idea
团队得出结论后、正式起草报告前，把时间快进到"未来"，假设该方案已经失败，从未来回溯今天解释失败原因。这利用了"后见之明"的认知优势——从失败回头解释原因，比正向预测失败容易得多。其真正威力在于：让不同意见**合法化**，绕过团队成员"怕被视作不忠诚"的沉默压力。

## Framework / Mental Model
- **Gary Klein 时间反转框架（Temporal Inversion）**：把"未来会成功吗？"反转为"未来已经失败了，为什么？"
  - When to use: 团队就分析/方案达成共识后、定稿前；只需 5 分钟。
  - How: 主持人宣布场景 → 每人独立写下失败原因 → 轮流陈述 → 汇总并指派应对。

## Key Concepts
- **后见之明优势（Hindsight Advantage）**：人类解释"已发生"事件的能力，远强于预测"将发生"事件。Pre-mortem 骗大脑进入"已发生"模式。
- **不同意见合法化**：把"我反对"改写为"我在配合做失败推演"，消除唱反调的社交成本。
- **名义团体法（Nominal Group Technique）**：轮流发言而非自由讨论，防止单个人主导。
- **对抗过度自信 / 计划谬误**：成功情境下大脑自动生成乐观理由；失败情境下才肯认真思考风险。
- **早期预警指标**：副产品——识别出"事态未按预期发展"的可观察信号。

## 操作步骤 (Procedure)
1. 团队达成共识后，主持人宣布："现在设想已过了一年，我们的方案彻底失败了。请每个人独立写下最可能的失败原因。"
2. 给 3–5 分钟独立书写，不讨论。
3. 用名义团体法轮流陈述：每人一次说一条，记录到白板，循环到所有观点列出。
4. 团队讨论每条失败假说：是否成立？如何防范？是否需要修改原方案？
5. 提炼出"早期预警指标"清单，用于后续监控。
6. 如失败假说暴露了根本性缺陷，回到分析阶段修改判断。

## Worked Example
**场景**：情报团队结论"X 国未来 12 个月不会发动军事行动"。主持人宣布："假设一年后该结论被证明完全错了，X 国确实动了武。最可能的失败原因是什么？"
- 失败假说 1：我们假定 X 国领导人 A 是理性的，但他实际上被强硬派架空了。
- 失败假说 2：我们把兵力调动误读为演习，因其演习与实战程序高度相似。
- 失败假说 3：第三方 Y 国与 X 国达成秘密协议，改变了 X 国的成本收益计算。
- 失败假说 4：经济制裁比预期更弱，反而让 X 国觉得"窗口期"正在关闭，必须趁现在动手。
→ 团队据此补充监控指标："强硬派人事变动""演习规模异常""Y 国特使访问"。

## 适用场景 (When to Use)
- 团队刚对一项未来导向的判断/计划达成共识，定稿前。
- 团队氛围偏附和，成员不敢直接表达异议。
- 高利害、不可逆决策（军事行动、重大投资、战略发布）。
- 个人分析也可用：写完结论后自问"如果一年后被证伪，原因会是什么？"

## 对抗的认知偏见 / 核心价值
- **过度自信（Overconfidence）**：人对自己的判断普遍高估准确度。强制失败情境迫使人面对不确定性。
- **计划谬误（Planning Fallacy）**：低估时间、成本、风险。Pre-mortem 直接戳破"一切会按计划进行"的幻觉。
- **核心机制——时间反转（Temporal Inversion）**：不是问"会失败吗？"，而是"已经失败了，为什么？"。这一重构绕过了大脑的防御性乐观——当成功仍是默认情境时，任何风险提示都被压制；当失败已是既定事实，大脑才肯认真寻找原因。这就是 5 分钟能产生大效果的原因。
- **团体压力下的自我审查**：让"挑刺"变成"配合任务"，降低社交成本。

## 与其他方法的关系
事前分析负责**发现**薄弱点，结构化自我批判法（6.2）负责**系统解决**这些问题；二者是前后承接关系。

## Anti-patterns / 潜在缺陷
- 只罗列风险，不指派跟踪指标 → 失败假说沦为纸上谈兵。
- 主持人过早表态，暗示"正确答案"，污染独立思考。
- Pre-mortem 不能定量评估各失败情景的概率，需配合其他方法综合评估。

## Key Takeaways
- **5 分钟投入，超高回报**：Gary Klein 设计、CIA 采纳的最具性价比的质疑方法。
- 关键不在"想风险"，而在"假装失败已发生"——这是认知开关。
- 用名义团体法收集，避免领导或强势成员主导。
- 副产品是早期预警指标，把质疑成果转化为可监控的信号。
- 让异议合法化，是这个方法最深层的组织价值。

## Connects To
- **6.2 结构化自我批判法**: Pre-mortem 发现问题，Self-Critique 系统化追问——前后承接。
- **6.3 若则分析法**: 同样用"假设事件已发生 + 逆向推理"，但 What If 改变的是某个具体变量，Pre-mortem 改变的是时间视角。
- **关键假定检查（外部方法）**: Pre-mortem 揭示的关键假定可由该法进一步检验。
