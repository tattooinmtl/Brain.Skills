# 1.13 — 流程图和甘特图（Process Maps and Gantt Charts）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第一类 分解与可视化
**编号**：1.13

## Core Idea
流程图示法是识别复杂程序每一步骤并将其标记在图中的宏观术语；甘特图是流程图的特殊类型，用矩阵形式（左侧列任务，顶行时间，横条显示起止）规划复杂项目。在情报领域二者用于跟踪、监控外国政府、犯罪或恐怖组织的活动进展——回答"他们正在干什么？进展到什么程度？还需要做什么？还需要什么资源？在这一过程中是否存在弱点？"

## Framework / Mental Model
- **流程图示法（Process Mapping）**：宏观术语涵盖活动流程图、商品生产流程图、因果流程图等
  - When to use: 需跟踪、了解并监控某行为体活动进展时；需理清复杂过程依赖关系和关键路径时；需向用户直观交流复杂过程时
  - How: 识别每步骤→用带箭头符号（起点/终点/决定/行动）按顺序画出→可用 Visio 等软件
- **甘特图（Gantt Chart）**：流程图特殊类型，使用矩阵形式规划复杂项目
  - When to use: 武器系统开发监控、恐怖袭击准备跟踪、军事行动规划分析等
  - How: 最左列任务/步骤→顶行预计时间→每任务用横条显示起止→先输入顺序性任务再并行任务→对比预判与实际找空白异常
- **预判 vs 实际对比**：将预判的事件列表与实际观察数据在甘特图中分层对比，以检验假设、识别异常
  - When to use: 拥有历史模式可对照时
  - How: 不同颜色或线条类型标注新信息，识别数据空白和异常

## Key Concepts
- **流程图示法（Process Mapping）**：识别复杂程序每步骤并标记在图中的宏观术语
- **甘特图**：流程图特殊类型，矩阵形式（任务×时间）规划复杂项目
- **顺序性任务**：需前一任务完成后才能开始的任务
- **并行任务**：不依赖其他任务完成的任务，避免与关键路径上的顺序性任务相互干扰
- **关键路径**：项目最长的顺序性任务链，决定项目总时长

## 操作步骤 (Procedure)
**流程图绘制**：
1. 识别复杂程序的每个步骤，按照顺序使用代表起点、终点、决定和行动的带箭头符号画出流程图。
2. 可使用 Microsoft Visio 等画图软件制作。

**甘特图绘制**：
1. 在矩阵最左侧列中列出课题的所有任务或过程的步骤。
2. 在矩阵顶行列出完成这些任务或步骤所需的预计时间（按周、月或年计算）。
3. 就每项任务或每个步骤而言，用横线或横条显示该任务或步骤的开始和结束时间。
4. 先输入顺序性任务（需要在前一任务完成后才能开始的任务），确保依赖关系正确。
5. 在合适的时间框架中，在矩阵中依次输入并行任务（不依赖于其他任务完成的任务），避免与关键路径上的顺序性任务相互干扰。
6. 可使用 Microsoft Project、Excel 或手工绘制。
7. 通过对已知的或预判的活动与实际数据资料进行对比分析，用不同颜色或线条类型标注新信息，识别数据空白和异常。

## Worked Example
**示意**：监控某国弹道导弹开发项目。甘特图依历史模式预判：T0 设计→T+12 月发动机测试→T+24 月飞行试验→T+36 月部署。实际数据对比发现：飞行试验在 T+18 月就出现——比预判早 6 个月。用红色标注此异常后，分析员推断可能存在外部技术援助，加速了开发节奏。这是预判 vs 实际分层对比的典型应用。

## 适用场景 (When to Use)
- **何时使用**: 需要跟踪、了解并监控某一行为体的活动进展时；需要理清复杂过程中的依赖关系和关键路径时；需要向用户直观交流复杂过程的信息时
- **适合的问题类型**: 武器系统开发监控、恐怖袭击准备跟踪、军事行动规划分析、犯罪组织运作模式识别、信息来源链追踪、个人极端化过程研究
- **团队还是个人**: 个人或团队均可
- **预期产出**: 流程的步骤图解或甘特图进度表，显示任务依赖关系、时间安排、关键路径以及数据空白

## 对抗的认知偏见 / 核心价值
作为范式 Ⅳ 流程工具，本方法对抗的核心偏见是**进度幻觉**——分析员凭零散情报片段在脑海中拼凑出"对方大概进展到某阶段"的直觉判断，而无系统框架验证。甘特图通过将预判进度显性化为时间线，让实际数据与预判的偏离立刻可见。第二个对抗的偏见是**线性外推偏差**：分析员倾向假设对方按部就班推进，而甘特图的"并行任务"维度强制考虑加速的可能性。

## 与其他方法的关系
甘特图本质上是一种特殊类型的矩阵（使用矩阵分析任务与时间的关系）。分析人员可将预判的事件列表与实际观察到的数据在甘特图中分层对比，以检验假设、识别异常。

## Anti-patterns / 潜在缺陷
- **信息源依赖**：对信息来源要求较高。如果信息不完备，流程图和甘特图可能呈现不完整或误导性的画面
- **依赖关系判定错误**：任务之间的依赖关系判定错误会导致时间预估严重偏差
- **信息过时**：网络不断变化的特性可能导致信息过时，需要经常对数据进行审查和图表更新

## Key Takeaways
1. 流程图偏逻辑顺序，甘特图偏时间进度
2. 顺序性任务决定关键路径
3. 预判 vs 实际分层对比可识别异常与加速
4. 依赖关系判定是时间估计的关键变量
5. 信息源不完备 = 图表误导性
