# 8.6 — 影响矩阵法（Impact Matrix）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第八类 决策支持
**编号**：8.6

## Core Idea
某决策涉及哪些关键行为体？每个行为体对此问题有多在意？决策对每个行为体产生何种影响？三问构成矩阵，让分析者预判政策被接受程度、最可能发挥的作用、最有效的策略。核心关注点：发现将受**严重负面影响**的行为体，在政策宣布**之前**接触他们。

## Framework / Mental Model
- **利益 × 影响二维表**：行为体为行，列为"重要性（低/中/高）"与"影响方向（最积极 P / 中性 O / 最消极 N）"。
  - When to use：即将宣布新政策、强制性变革，或评估公众对外国行为的反应时
  - How：列行为体 → 评重要性 → 评影响方向 → 识别 P/N 极端值 → 行动计划
- **预先接触原则**：受重大消极影响的行为体必须在宣布前接触，了解他们对政策优化的想法。

## Key Concepts
- **行为体（Actors）**：上级、下属、用户、同事、同级部门、外国政府、利益集团、公众群体——必须穷尽。
- **重要性三级**：低 / 中 / 高——行为体对该问题的关注程度。
- **影响方向三级**：P（最积极）/ O（中性）/ N（最消极）——决策对该行为体的作用方向。
- **极端象限优先**：高重要性 × N = 高风险阻力源；高重要性 × P = 关键盟友。
- **静态快照局限**：矩阵不反映行为体的动态演变——需周期性重做。

## 操作步骤 (Procedure)
1. 确定决策涉及的所有个人或团体（上级、下属、用户、同事、同级部门人员等）。
2. 就问题对每个行为体的重要性评级（低 / 中 / 高）。
3. 分类决策对每个行为体的影响（P 积极 / O 中性 / N 消极）。
4. 完成矩阵后，评估政策总体的可能反应。
5. 形成行动计划。
6. 确定重大消极影响所在，考虑事先协商的效用。
7. 确定重大积极影响所在，考虑关键行为体的支持。
8. 宣布决策并监控反应。
9. 根据反馈重新评估行动计划。

## Worked Example
某国政府拟发布新移民政策声明。行为体矩阵摘录：

| 行为体 | 重要性 | 影响 | 行动 |
|---|---|---|---|
| 边境州政府 | 高 | N | 宣布前协商，听取执行成本反馈 |
| 移民社区团体 | 高 | P | 邀请站台，强化正面叙事 |
| 工商业联合会 | 中 | P | 公开背书 |
| 反对党 | 高 | N | 预判攻击点，准备反驳口径 |
| 国际人权 NGO | 中 | N | 提前简报，争取"建设性批评"立场 |

边境州政府（高 × N）和反对党（高 × N）是预先接触优先——前者可协商优化，后者至少预判其攻击角度。

## 适用场景 (When to Use)
- 即将制定主要新政策或宣布强制性变革。
- 需评估公众对外国行为的反应。
- 政策影响评估、行为体分析、战略沟通。
- 管理人员作为团队过程使用，或单个情报分析人员使用。

## 对抗的认知偏见 / 核心价值
**行为体盲点**：决策者默认只看到最显眼的相关方（如直接监管者），遗漏**非显眼但受重大影响**的行为体（如边缘社区、二级供应商、海外盟友）。影响矩阵强制穷尽行为体清单，反制"只看见熟悉面孔"的倾向。

## 与其他方法的关系
可作为 **8.7 复杂性管理程序法** 的组成部分——识别关键行为体及其关系是复杂性管理的重要步骤。

## Anti-patterns / 潜在缺陷
- 难以预测消极行为体的**真正**反应——他们的反应往往比矩阵标注的更激烈。
- 分析正确性通常需结合领域专家意见。
- 静态快照，不能完全反映行为体的动态变化——宣布后需重新评估。

## Key Takeaways
- 行为体 × 重要性 × 影响方向 = 三维矩阵。
- 重大消极影响行为体必须**宣布前接触**。
- 极端象限（高 × N 与 高 × P）优先处理。
- 静态快照需周期性更新。

## Connects To
- **8.7 复杂性管理程序法**：本方法是其组成部分之一。
- **8.4 力场分析**：力场把行为体作为推动/约束力量评估强度；影响矩阵评估其利益与受影响方向——互补。
- **红帽分析法**：可借用其框架推断对手行为体的反应。
