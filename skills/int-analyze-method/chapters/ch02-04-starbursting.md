# 2.4 — 星爆法（Starbursting）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第二类 观点生成
**编号**：2.4

## Core Idea
星爆法是头脑风暴的一种形式，但它**专注于提出问题而非解答问题**。核心理念：提出正确的问题，往往是找到正确答案的先决条件。方法借用新闻记者的6问——何人、何事、如何、何时、何地、为何——置于六角星的6个角上，针对每个词展开头脑风暴，生成尽可能多的相关问题。

## Framework / Mental Model
- **5W1H 六角星框架**：六角星6角分别标 Who/What/How/When/Where/Why
  - When to use: 研究项目确定后、明确需解答问题之前
  - How: 每角头脑风暴提问 → 排序或分类 → 通常仅3–4词与情报问题直接相关

## Key Concepts
- **问题优先**：不解而问，先穷尽问题再求答案。
- **5W1H**：何人、何事、如何、何时、何地、为何，源自新闻学。
- **六角星形**：可视化锚点，强制覆盖所有疑问维度。
- **适应性裁剪**：通常只有三四个词与情报问题直接相关（如"何时/何地"答案已明确），可跳过。

## 操作步骤 (Procedure)
1. 画出六角星形，6角分别写：何人、何事、如何、何时、何地、为何。
2. 确定要分析的观点、议题或问题。
3. 针对每个词展开头脑风暴，**提出尽可能多的问题**（而非答案）；通常按6角顺序讨论。
4. 仅三四个词与情报问题直接相关时可跳过其余。
5. 对所有词提问后，要求团体区分问题优先次序，或整理到合理类别。

## Worked Example
**示意**：分析"Z国网络行动意图"。画六角星，"何人"角提出：军方？代理黑客？爱国组织？"为何"角提出：情报窃取？威慑？商业利益？共得34问，排序后前8问进入指标设计与因果分析阶段。

## 适用场景 (When to Use)
- **何时使用**: 决定研究项目后、明确需解答问题之时。
- **适合的问题类型**: 课题定义与范围界定阶段。
- **团队还是个人**: 团体或个人均可。
- **预期产出**: 一份经排序的研究问题清单。

## 对抗的认知偏见 / 核心价值
对抗**急于求解**的认知惯性——分析人员常跳过问题界定直奔答案。星爆法强制先穷尽提问，确保研究范围完整、关键问题不被遗漏，是后续因果分析与指标设计的边界守门人。

## 与其他方法的关系
可与 **启动清单法** 和 **问题再定义法** 有效结合；与第八章**因果分析**直接相关；也用于 **指标验证因子法™** 中对分析过程的排序。

## Anti-patterns / 潜在缺陷
- 不要只就提出的问题来回答——应专注提出尽可能多的问题。
- 误用为答案生成工具，背离"问题优先"初衷。

## Key Takeaways
1. 问题优先，答案其次
2. 5W1H 强制全覆盖
3. 仅3–4词常相关，可裁剪
4. 范围界定的守门员
5. 个人或团体皆宜

## Connects To
- **问题再定义法 / 启动清单法**: 课题定义阶段的组合工具。
- **指标验证因子法™**: 为分析过程排序提供问题集。
- **范式 Ⅳ**: 结构化协作工具家族。
