# 5.1 — 关键假定检查法（Key Assumptions Check）

**范式归属**：范式Ⅲ：认知心理学/证伪主义范式
**方法类别**：第五类 因果评估
**编号**：5.1
**★ 核心方法（recommended in 原书结语）**

## Core Idea
任何分析判断都建立在证据与"先入之见"（假定）的结合之上，而这些未经检验的假定往往是分析链条中最薄弱的环节。本方法强迫分析人员把隐含假定摊到桌面上逐一质疑——弗森的经验数据显示，约四分之一的"关键假定"经审查后会被毙掉或降级为"关键不确定性"。它廉价、快速、却直击情报失误的根源。

## Framework / Mental Model
- **假定显性化—批判—重分类三阶段模型**：思维模型 → 假定清单 → 批判性审查 → 三级归类
  - When to use: 分析早期、协调过程中、结论提交前均可，越早越值
  - How: 局外人入会 → 沉默头脑风暴 → 标记触发词（"永远""必将""一般而言"）→ 四问法审查 → 三级归类 → 转化为搜集需求

## Key Concepts
- **先入之见 / 思维模型**：分析人员对证据的解读过滤网，决定看得到什么、忽略什么
- **关键假定**：一旦错误就会颠覆分析结论的假定——区别于无关紧要的背景假定
- **关键不确定性**：经审查后既无法证实也无法证伪的假定，应转化为情报搜集需求
- **触发词识别**：从"永远""绝不""必将""基于""一般而言"等短语中嗅出尚未被质疑的假定
- **局外人价值**：原有团队已有既定思维模型，局外人才能带来真正的新视角
- **整体出错概率**：结论不会比推理链中最薄弱环节更可靠——逐环节概率相乘

## 操作步骤 (Procedure)
1. 召集小团体 + 几名"局外人"（课题外人员），打破既定思维。
2. 沉默头脑风暴：每人独立在卡片上写下若干假定，避免从众。
3. 汇总卡片，白板列出全部假定供所有人查看。
4. 用新闻记者式发问补全清单（何人/何事/何时/何地/为何/如何）；扫描"永远""必将""一般而言"等触发词。
5. 对每项假定执行四问批判：①我为何确信它正确？②何种情况下它可能不正确？③它过去正确现在是否仍正确？④若它无效，对分析影响多大？
6. 三级归类：基本可靠 / 限定条件下正确 / 无支撑或有疑问（即关键不确定性）。
7. 精简清单，删除经不起审查者，标注"一旦错误即颠覆结论"的高敏假定。
8. 将关键不确定性转化为情报搜集需求或研究课题。
9. 评估整体出错概率，估算结论大致正确的概率。

## Worked Example
**问题**：某国 X 近期大规模调动边境军队，是否即将对邻国 Y 发动进攻？

| # | 假定 | 审查结论 |
|---|------|----------|
| 1 | X 国军队调动必然意味着进攻意图 | **需质疑**——历史上 X 国多次以演习掩护换防、冬季拉练；应区分"姿态"与"意图" |
| 2 | X 国领导层是理性成本-收益计算者 | **需质疑**——个人威望、意识形态承诺可能压倒物质计算 |
| 3 | Y 国的盟友 Z 必将出兵干预 | **不成立**——Z 国国内正值大选、经济衰退，干预意愿低；应作为关键不确定性 |
| 4 | 卫星图像显示的集结规模即真实规模 | **成立**（限定条件下）——多源交叉验证一致，但仍需排查伪装/佯动 |

据此，"X 即将进攻"的结论依赖假定 1+2，两者均存疑，整体出错概率高——应转为情报搜集需求：监测 X 国后勤弹药前置、政治宣传调门、盟友外交信号。

## 适用场景 (When to Use)
- **何时使用**：分析过程早期最佳；协调过程中、结论提交前仍极具价值；起草报告前后值得再做一次。
- **适合的问题类型**：涉及意图、能力判断的情报评估；填补信息空白时的推理分析。
- **团队还是个人**：需多人配合，包括课题外的"局外人"。
- **预期产出**：一份清理过的假定清单（标出关键不确定性）+ 对结论准确概率的总体评估。

## 对抗的认知偏见 / 核心价值
- **未经检验的假定（unexamined assumptions）**——这是本方法的靶心。原书结语将本方法列为"核心方法"的原因正是：它是所有结构化方法中**性价比最高**的一种——几乎零成本、可在数小时内完成，却直接戳穿情报失误最常见的根源。
- **过早下结论 / 第一印象锚定**——四问审查强迫分析人员在数据稀少时不下定论。
- **终结偏差（confirmation bias）**——刻意搜寻"在什么情况下该假定可能不正确"。
- **信息缺失忽视**——步骤要求评估"假定无效时的分析影响"，强迫面对缺失证据。

## 与其他方法的关系
关键假定检查法与竞争性假设分析法（ACH）有特别互动：关键假定应作为"证据"列入 ACH 矩阵；若某假定至关重要但正确性存疑，可进一步用"若则分析法"（6.2）想象其不成立时的情形。

## Anti-patterns / 潜在缺陷
- **表面合规**：把假定清单当"打勾流程"，未真正执行四问批判——这是最常见的失败模式。
- **开放心态缺失**：分析人员对自己犯错的可能性持开放心态是最困难的一步，没有捷径。
- **终结偏差反噬**：列出假定后倾向只搜支撑信息，须主动寻找反向证据。

## Key Takeaways
- 假定不是分析的输入，而是分析最脆弱的部分——约 1/4 经审查后会被毙掉。
- 几乎零成本、数小时可完成，却是原书结语推荐的"核心方法"——最被低估、最该常态化使用。
- "局外人 + 沉默头脑风暴 + 触发词扫描"三件套是发现隐性假定的关键。
- 关键不确定性应转化为情报搜集需求，而非继续作为"既定前提"使用。
- 任何结论的可靠度 ≤ 推理链最薄弱环节的可靠度——务必逐环节估算。

## Connects To
- **竞争性假设分析法 (ACH, 4.4)**：关键假定作为"证据"列入 ACH 矩阵
- **若则分析法 (6.2)**：对存疑的关键假定做"如果它不成立"的推演
- **象限处理法 / 简单情景法**：均以对立假定生成多解释或多结果
- **结构化自我批判 (6.2)**：假定检查是自我批判的前置步骤
