# 7.1 — 对抗性协作法（Adversarial Collaboration）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第七类 冲突管理
**编号**：7.1

## Core Idea
对立双方就如何合作解决分歧（或至少更好地理解分歧）达成正式协议，最终产出一份双方共同署名的报告，分歧本身也写入报告。由卡尼曼提出，旨在替代社会科学界无效的"批判—回应—再反驳"循环。

## Framework / Mental Model
- **联合探究契约（Joint Inquiry Contract）**：双方真诚合作研究同一问题，焦点从"说服对方"转向"理解对方证据、逻辑、假定"，尤其在与己方首要假设冲突的证据上停留。
  - When to use：双方开诚布公、均有合作意愿时
  - How：6 种可选技术（关键假定检查 / 竞争性假设分析 / 论证图示 / 相互了解 / 联名上交矛盾 / 诺申科法）

## Key Concepts
- **批判—回应—再反驳的失败**：几乎无人认错，几无人从对方学到东西——这是该方法的反例与动机。
- **共同署名报告**：分歧不被隐藏，而是作为正式产出的一部分提交上级。
- **相互了解法**：A 复述 B 的立场直到 B 承认"是的，你理解我了"——理性讨论的前置条件。
- **主持人角色**：建议配备中立主持人维持协作契约。
- **CIA 应用语境**：该方法被情报界采纳，专门用于处理分析人员之间的分歧，避免升级为正式调解或管理层介入。

## 操作步骤 (Procedure)
1. 双方签订协作契约，同意共同研究而非相互反驳。
2. 选择 6 种技术之一（或组合）作为协作载体：
   - 关键假定检查：双方共同执行，讨论聚焦反驳对方假定而非支持己方。
   - 竞争性假设分析：先就假设清单达成一致，再就证据—假设一致性评分。
   - 论证图示：共同绘制逻辑关系图，定位对立论据弱点。
   - 相互了解：轮流复述对方立场直至对方确认无误。
   - 联名上交矛盾：起草分歧联合声明并列名提交上级。
   - 诺申科法：各方认定关键证据并交对方讨论。
3. 共同撰写报告，分歧部分明确标注。
4. 共同识别后续研究步骤。

## Worked Example
分析员 A 认为 X 国将在 6 个月内试射导弹；分析员 B 认为不会。两人采用"相互了解法"：A 复述 B 的立场（"你认为燃料工厂尚未满产"），B 确认；B 复述 A 的立场（"你依据卫星图像中新增的运输车"），A 确认。随后双方就"运输车数量是否必然推导出试射"展开联合调查，最终报告中保留两种判断并注明关键证据分歧。

## 适用场景 (When to Use)
- 双方开诚布公、有合作意愿但观点对立。
- 情报/政策/商业领域需要协调立场的复杂问题。
- 希望减少将分歧推向上层裁决的频率。
- 至少有两方持对立意见且配备主持人。

## 对抗的认知偏见 / 核心价值
**分歧极化 / 信任崩塌**：传统处理方式（强促共识或淡化分歧）会让分歧转入地下并恶化。对抗性协作通过结构化契约把冲突变成学习经验，把"分歧的存在"本身合法化。

## 与其他方法的关系
当双方完全坚持己见、反复反驳而无法协作时，应转为 **7.2 结构化辩论法**，由中立方裁决。

## Anti-patterns / 潜在缺陷
- 一方缺乏真诚合作意愿则无法启动——契约前提不可绕过。
- "相互了解法"要求认真倾听对方，否则流于形式。
- 需充分时间探索，不可压缩为单次会议。

## Key Takeaways
- 把对立变为联合研究，最终产出共同署名报告。
- 6 种技术可单独或组合使用；关键是"反驳对方假定"而非"捍卫己方假定"。
- 解决分歧的目标优先于判定胜负——分歧本身就是合法产出。
- 信任是入场券，主持人是稳定器。

## Connects To
- **7.2 结构化辩论法**：协作失败时的升级路径，由中立评判组裁决。
- **竞争性假设分析法（ACH）**：作为协作技术之一，可独立用于诊断分歧所在。
- **关键假定检查法**：6 种技术之首，常作为协作起点。
