# 6.2 — 结构化自我批判法（Structured Self-Critique）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第六类 质疑分析
**编号**：6.2

## Core Idea
让团队全体成员"戴上黑帽"，从分析的支持者**转变为批判者**，按一份固定清单系统自问：不确定性来源、关键假定、证据诊断力、异常证据、信息空白、替代模型、欺骗可能……改变参照系能激活不同脑区，绕开既定神经通道，让原先被"一致性压力"压制的疑虑浮出水面。

## Framework / Mental Model
- **黑帽角色重构 + 11 维度清单**：全员切换角色，逐一回答 11 类质疑问题。
  - When to use: 分析定稿前的最终复核；事前分析法发现疑点后的跟进；化解团队内部分歧。
  - How: 宣布切换角色 → 按 11 个维度逐项头脑风暴 → 重新评估信心度。

## Key Concepts
- **角色反转（Role Reversal）**：从"我要证明我对"切换到"我要找出我哪里错了"。
- **谜式 vs 拼图式问题**：拼图式有确定答案（找碎片）；谜式无确定答案（多因素互动）——后者证据永远不足，更需要批判。
- **关键假定反转测试**：哪一两个假定一旦错误，整篇分析就崩塌？把它反转，是否反而支持替代假设？
- **缺失证据（Missing Evidence）**：如果判断正确，应出现却未出现的证据，比"出现的证据"更有诊断力。
- **对抗自我证实倾向（Self-Confirmation Bias）**：人倾向于只找支持自己的证据，黑帽强制找反证。
- **替代决策模型**：是否默认对手是"理性行为者"？是否考虑官僚政治模型、组织程序模型、独裁者心血来潮模型？

## 操作步骤 (Procedure)
1. 主持人宣布全员戴上"黑帽"，评判标准改为"发现薄弱环节的能力"。
2. 逐一讨论以下维度（每项用头脑风暴）：
   - **不确定性来源**：拼图还是谜？证据质量与时效？是否假定过多？
   - **分析流程**：是否检验了替代假设？是否征求外单位意见？
   - **关键假定**：哪个假定错了会推翻结论？反转后是否支持替代假设？
   - **证据诊断力**：什么证据能让你否决替代假设？
   - **信息空白/缺失证据**：预期出现却未出现的证据？
   - **异常证据**：被判定"不重要"的异常，是否其实指向替代假设？
   - **大环境**：社会/技术/经济/环境/政治宏观变革？
   - **替代决策模型**：是否只用了理性行为者模型？
   - **文化知识**：是否真懂对方文化与决策逻辑？
   - **欺骗**：对手有无动机、机会、手段对我方实施战略欺骗？
3. 全员"脱帽"，重新评估对原判断的信心度，决定维持或修改。

## Worked Example
**场景**：团队结论"Z 组织将优先发展核武器而非生化武器"。戴黑帽后逐项追问——
- 关键假定："Z 组织视核武器为最高威慑"——反转：若其判断生化武器更难追溯、更易部署呢？
- 缺失证据："如果真在搞核，应看到离心机采购异动，但情报完全没有"——是情报空白还是反向证据？
- 替代模型：是否套用了冷战苏联式理性计算模型，而 Z 组织实际按宗教末日论决策？
→ 团队将信心度从"高"下调至"中"，并补办生化设施监控。

## 适用场景 (When to Use)
- 重要报告发布前的最终复核程序。
- Pre-mortem（6.1）已暴露疑点，需要系统追问。
- 团队内意见冲突，需要把分歧结构化呈现。
- 怀疑当前分析套用了错误的对手决策模型时。

## 对抗的认知偏见 / 核心价值
- **自我证实倾向（Confirmation Bias）**：11 维度清单强制覆盖反证、缺失证据、替代模型——这些正是自我证实倾向会刻意回避的领域。
- **锚定效应**：一旦团队锁定某个判断，后续思考都围绕它打转。黑帽强制切换参照系，激活新神经通道。
- **角色惯性**：人很难既当辩方又当判官。强制角色反转解决这一难题。
- 11 维度清单的价值在于**防遗漏**——它是质疑的"checklist"，确保每个已知的薄弱环节类别都被触及。

## 与其他方法的关系
视为魔鬼代言人（6.5）的进阶版——魔鬼代言人只一人唱反调，其余人会本能自我辩护；结构化自我批判让**全员**都戴黑帽，分散了被针对的压力，更有效。

## Anti-patterns / 潜在缺陷
- 团队成员缺乏智力灵活性，戴不上黑帽——需换主持人、换地点、正式化角色以辅助。
- 流于形式：11 维度草草过场，每项只答"没问题"。
- 脱帽后不真正下调信心度，批判成果未落地。

## Key Takeaways
- 全员批判 > 单人批判：分散社交压力，避免"一人 vs 全队"的对抗结构。
- 11 维度清单是核心资产——它是多年情报失误教训的结晶。
- "缺失证据"和"替代决策模型"两项最常被忽略，却最具诊断力。
- 必须真正调整信心度，否则只是走过场。
- 与 Pre-mortem 配对使用效果最佳：先发现，再深挖。

## Connects To
- **6.1 事前分析法**: Pre-mortem 抛出疑点，Self-Critique 系统化追问。
- **6.5 魔鬼代言人**: 本法是其全员化升级版，解决"单人被针对"的缺陷。
