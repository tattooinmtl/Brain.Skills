# 2.7 — 经典象限处理法™（Classic Quadrant Crunching™）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第二类 观点生成
**编号**：2.7

> **商标说明**：Quadrant Crunching™ 是伦道夫·弗森联合公司（Pherson Associates）的商标化分析技术，2006 年开发，2007 年首次发表于弗森《分析工具与方法手册》。本方法名称须保留 ™ 符号。

## Core Idea
经典象限处理法™ 是形态分析法的一种特殊应用，通过**检验所选定关键变量的多种可能组合**帮助分析人员避免意外突发。它结合关键假定检查法与多种情景生成法，促使分析人员**确认并系统地质疑首要假设所依据的所有假定**，探究对立假定的意义，发现"我们不知道所不知道的事情"——即**未知的未知**。

## Framework / Mental Model
- **Pherson 2×2 象限证伪框架™**：首要假设 → 关键假定 → 双正交维度 → 4象限情景
  - When to use: 可用数据少、意外突发概率高的高度复杂不明朗形势（如反恐、竞争反应）
  - How: 表述首要假设 → 选2个最不确定假定作正交维度 → 画2×2 → 每象限描述情景 → 识别指标与概率影响

## Key Concepts
- **未知的未知（Unknown Unknowns）**：本方法核心对抗的对象，通过穷举象限使之显形。
- **关键假定质疑**：被誉为"对类固醇进行的关键假定检查法"——系统剖析首要假设依赖的每个假定。
- **正交维度**：从所有假定中选出两个最重要、最不确定的，作为2×2矩阵的两轴。
- **证伪主义**：通过探究对立假定的意义，对首要假设进行证伪压力测试。

## 操作步骤 (Procedure)
1. 明确表述首要假设。
2. 识别支撑该假设的所有关键假定。
3. 从中选出两个最重要、最不确定的假定作为两个正交维度。
4. 阐明每个维度的两端（极端情况）。
5. 画出一个2×2矩阵，四个象限代表四种可能组合。
6. 为每个象限描述一个情节/情景。
7. 系统地质疑：哪些之前未被考虑的组合现在浮现？
8. 识别每种结果的指标。
9. 评估这些结果的发生概率和潜在影响。

## Worked Example
**示意**：首要假设"X组织不会在未来1年发动海外袭击"。关键假定含"资金充足""指挥链完整""海外据点存在"。选"资金"与"指挥链"为正交维度，2×2得4象限：高资金+断裂指挥链浮现出"特许独狼式袭击"——此前未认真考虑的高影响情景。

## 适用场景 (When to Use)
- **何时使用**: 可用数据资料很少、意外突发概率高的高度复杂不明朗形势，如确认恐怖分子可能袭击的多种方式，或商业竞争者对新产品发布的反应。
- **适合的问题类型**: 需要穷举可能性的反恐、安全、竞争情报问题。
- **团队还是个人**: 团体，需培训和经验丰富的指导人员。
- **预期产出**: 四种或更多可能情节及其指标。

## 对抗的认知偏见 / 核心价值
核心对抗**未知的未知**与**首要假设锚定**——分析人员易将首要假设视为默认真。本方法系统质疑首要假设依赖的每个假定，探究对立假定的意义，让"我们不知道所不知道的事情"通过象限穷举浮出水面，减少事件以从未被考虑方式发展的概率。

- 首次使用强烈建议有经验丰富的指导人员辅导。
