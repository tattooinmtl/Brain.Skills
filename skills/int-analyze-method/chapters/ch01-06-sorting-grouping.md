# 1.6 — 分类整理法（Sorting, Categorization, and Grouping）

**范式归属**：范式 Ⅰ：实证主义/经验描述范式
**方法类别**：第一类 分解与可视化
**编号**：1.6

## Core Idea
把大量材料分类整理到可相互比较的相关类别中，让分析员发现趋势、相似点、差异或异常——这些情报价值若不加分类则会被完全忽视。最有力的应用是**根据多个分类纲目对数据分类，并检查数据与类别之间的相关关系**。分析大师与优秀分析人员的区别在于：优秀者注意到趋势，大师注意到异常。

## Framework / Mental Model
- **多纲目交叉分类（Multi-dimensional Cross-categorization）**：根据多个分类纲目对同一组数据分类，检查相关关系
  - When to use: 信息要素能被分成若干大类或子类时；材料收集初期和假设生成阶段特别有效
  - How: 选定主要类别+次要类别→归入数据→按类别审查找规律异常→用替代分类纲目交叉验证
- **趋势 vs 异常的二分**：优秀分析员看趋势，分析大师看异常
  - When to use: 处理往来数据如通信拦截、商品资金转移时
  - How: 系统分类后主动寻找不符合主模式的反常条目

## Key Concepts
- **纲目（Categories）**：根据数据特征确定的主次分类标题
- **相关关系≠因果关系**：相关关系并不等同于因果关系，这一边界需时刻清醒
- **替代分类纲目**：寻找其他可能的分类方式，避免单一分类的盲点
- **电子数据表/数据库**：按列区分数据类型（日期、时间、地点、人物、活动、数量等）
- **往来数据**：通信拦截、商品资金转移等适合分类整理的数据类型

## 操作步骤 (Procedure)
1. **审查信息类别**：确定何种类型类别或类别组合可揭示趋势或反常。将数据资料输入电子数据表或数据库，根据需要的列数区分数据类型（日期、时间、地点、人物、活动、数量等）。列出与分类计划有关的每个事实、每条信息或所有假设。
2. **审查找模式**：对数据库或电子数据表中列出的事实信息和假设进行审查，找出可能显示潜在模式或分组的关键领域。这些模式或分组即成为纲目类别，可列为标题。例：查询恐怖分子活动后发现大部分袭击发生在酒店饭店但袭击时间不固定，则"地点"是主要类别，"日期""时间"是次要类别。
3. **归入类别**：根据分类纲目，将上述内容归入第一步确定的类别中。
4. **单类别深审**：选择一个类别并对该类别中的材料进行分类，寻找规律、趋势或异常。
5. **替代分类交叉验证**：自行或让他人审查经过分类整理的事实信息或假设，寻找其他替代的分类方式。为要分析的问题列出替代分类纲目。根据多个分类纲目对数据资料进行分类，并检查数据资料与类别之间的相关关系。

## Worked Example
**from source**：查询恐怖分子活动后发现大部分袭击发生在酒店和饭店，但袭击时间不固定。则"地点"是主要类别，"日期""时间"是次要类别。进一步按"地点×武器类型"交叉分类后，可能发现酒店偏好爆炸物、饭店偏好枪击——这种模式若仅按时间分类则会被完全忽视。

## 适用场景 (When to Use)
- **何时使用**: 信息要素能够被分成若干大类或子类时；材料收集初期和分析的假设生成阶段特别有效
- **适合的问题类型**: 涉及大量数据资料的情报问题——通信拦截分析、资金流动追踪、军事活动分类、行为模式识别等
- **团队还是个人**: 个人或团队均可
- **预期产出**: 经过系统分类的数据集，以及基于分类呈现的模式、趋势、相似点、差异或异常

## 对抗的认知偏见 / 核心价值
作为范式 Ⅰ 实证方法，分类整理填补的分析盲点是**信息过载下的视而不见**——面对大量原始数据，分析员的工作记忆无法同时处理，隐藏的模式只能通过系统分类才能浮现。它通过强制结构化组织数据，把"脑海里浏览"升级为"看见结构"。注意：相关关系≠因果关系是该方法必须时刻清醒的边界——分类能揭示相关，但因果需要其他方法验证。

## 与其他方法的关系
作为基础性方法，分类整理法可与其他结构化分析方法配合使用，为假设生成、因果分析和预测评估提供组织有序的数据基础。

## Anti-patterns / 潜在缺陷
- **分类不当掩盖见解**：分类整理不合理反而会隐藏有价值的见解——正如合理分类可以阐明见解一样，不合理分类也可以掩盖它们。因此使数据资料分类标准化非常必要，与有经验的分类分析人员共事可避免大多数分类不当的情况
- **相关≠因果**：分析员可能将分类揭示的相关关系误读为因果关系——这是该方法必须时刻警惕的认识论陷阱

## Key Takeaways
1. 多纲目交叉分类 > 单一分类
2. 优秀看趋势，大师看异常
3. 分类不当比不分类更危险
4. 相关≠因果，永远保持清醒
5. 让他人审查分类，发现替代视角
