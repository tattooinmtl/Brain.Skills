# 8.4 — 力场分析法（Force Field Analysis）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第八类 决策支持
**编号**：8.4

## Core Idea
任何现状都是推动力与约束力的动态平衡。要让变化发生，推动力必须超过约束力。本方法列出所有推动/阻碍变化的力量并赋强度值（1-5），据此制定策略：促进变化则增强推力或削弱阻力；抑制变化则反向操作。由库尔特·卢因（Kurt Lewin）提出。

## Framework / Mental Model
- **力场平衡模型**：现状 = Σ 推动力 ↔ Σ 约束力。
  - When to use：项目初期定义问题、评估或实现某种变化、政策可行性评估时
  - How：头脑风暴列推动/约束两清单 → 1-5 评分 → 判断平衡 → 强化或削弱
- **不要加总分**：不可简单以两方总分定胜负——任何数值都可通过增加项操控。判断以专业直觉为准。

## Key Concepts
- **现状作为平衡态**：组织机构是系统，其稳定来自力场均衡——这是卢因的核心隐喻。
- **推动力（Driving Forces）**：促成变化的人、资源、需求、趋势、政策。
- **约束力（Restraining Forces）**：阻碍变化的传统、利益、态度、成本、法规。
- **不对称策略**：增强推力 vs 削弱阻力——通常削弱阻力更高效（推力增强常引发阻力反弹）。
- **以关键个人为立足点**：定义各种力量时以需被说服的关键人为锚。

## 操作步骤 (Procedure)
1. 清晰定义问题、目标或变化。
2. 头脑风暴所有相关力量（从需求、资源、成本、效益、组织、关系、态度、传统、利益、社会文化趋势、法规、政策、价值观、领导力等维度思考）。
3. 制作两份清单：推动变化的力量/人，与约束变化的力量/人。
4. 为每个力赋强度得分（1=最弱，5=最强）。
5. 检查两清单，判断支持力量是否超过制约力量——以专业判断，非加总分。
6. 制定行动计划：增强导致偏好结果的力量；削弱阻碍期望结果的力量。
7. 依目的决定重心：促进变化则增推力，抑制变化则增阻力。

## Worked Example
目标：在某部门推行新情报共享平台。

| 推动力（→） | 强度 | | 约束力（←） | 强度 |
|---|---|---|---|---|
| → 高层明令要求 | 5 | | ← 旧系统操作熟练 | 4 |
| → 跨部门协作需求紧迫 | 4 | | ← 数据安全顾虑 | 5 |
| → 新平台已采购（沉没成本） | 3 | | ← 一线人员抗拒 | 4 |

判断：约束力（13）略胜推动力（12），现状偏向不动。策略：削弱阻力优先——开展安全演示化解顾虑（针对强度 5 的安全顾虑），提供过渡培训降低抗拒（针对强度 4）。增强推力次之——把"高层明令"转为公开 KPI 落实（强度 5 的推力放大）。

## 适用场景 (When to Use)
- 项目或研究初期需要定义问题、收集数据、提出措施建议。
- 需评估或实现某种变化时。
- 需处理变化或解决冲突的问题。
- 政策可行性评估与变革管理。

## 对抗的认知偏见 / 核心价值
**系统盲点 / 现状偏见**：决策者常低估约束力（"这变化很简单"），同时高估推动力的实际效果。力场分析强制把隐含阻力显式列出并赋值，反制对现状的乐观低估——这就是 status quo bias 的解药。

## 与其他方法的关系
与管理学的变革管理理论同源。在政治与商业领域可用于开发推动政策的策略或确保结果出现的策略。应以需被说服的关键个人为立足点定义各种力量。

## Anti-patterns / 潜在缺陷
- **禁止加总分判胜负**——数值易通过增减项操控。
- 容易遗漏"沉默约束力"（如文化默认、潜规则）——必须刻意寻找。
- 静态快照，不反映力场的动态演变——需定期重做。

## Key Takeaways
- 现状 = 推动力与约束力的动态平衡。
- 两清单 + 1-5 强度评分，但**不以总分定胜负**。
- 削弱阻力通常比增强推力更高效。
- 以关键个人为锚定义力量。

## Connects To
- **8.5 SWOT**：SWOT 是 2×2 内外因分类；力场是推动/约束二分。前者偏战略评估，后者偏变革策略。
- **8.6 影响矩阵法**：影响矩阵识别行为体利益与影响；力场分析评估行为体作为力量的强度——可联用。
- **变革管理理论**：理论同源。
