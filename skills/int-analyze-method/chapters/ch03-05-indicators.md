# 3.5 — 指标法（Indicators）

**范式归属**：范式 Ⅰ：实证主义/经验描述范式
**方法类别**：第三类 情景与指标
**编号**：3.5

## Core Idea
用来**对未来情况提出预警或验证正在观察的情况**的经典经验方法——对军事攻击指标的识别与监控是"情报分析最古老的形式之一"。指标常与情景配对，识别多种可能情景中的哪一个正在形成。**只有在特定情景的背景下，指标才具有意义**：先确定情景及其相关指标，可让分析人员的思绪做好辨识重大变化早期迹象的准备。

## Framework / Mental Model
- **情景—指标配对（Scenario–Indicator Pairing）**：先有情景框架，再为每个情景配置可观察指标。
  - When to use：需跟踪特定情形随时间变化；与情景配对判断哪个正在形成。
  - How：制定清单 → 确保可靠性 → 增强完备性 → 指导搜集 → 档案化 → 定期更新。
- **预先承诺机制**：在工作初期就用客观、预设清单捕捉真实思考过程。

## Key Concepts
- **指标（Indicator）/ 标志物（Signpost）**：可观察、可追踪的事件或变量值，用于预警或验证。
- **可靠性（Reliability）**：数据搜集须一致，观察同样的事情，指标须准确定义。
- **完备性与可信度**：常通过多种方法组合（头脑风暴、假设生成、情景生成）增强。
- **指导搜集（Collection Guidance）**：指标清单是搜集工作的基础，并分发给所有利益方。
- **对抗数据缺口与凭直觉推理**：以系统化、预先承诺的客观清单取代心理捷径与事后合理化；同时克服**后见之明偏见**（hindsight bias）——清单记录了事前真实判断。

## 操作步骤 (Procedure)
1. **制定指标清单**：简单（草记预料会出现的事）或复杂（团体确定多种变量并对每个变量值排序）；常借助头脑风暴、假设生成或情景生成。
2. **确保可靠性**：数据搜集一致，观察同一事物，指标准确定义。
3. **增强完备性与可信度**：组合多种方法。
4. 将清单作为**指导搜集**的基础，相关信息发送给所有利益方。
5. 将清单作为**档案系统**基础，跟踪各指标的新进展。
6. **定期监控和更新**。

## Worked Example
**示意**：监控"Y 国政变可能性"。情景 A（军方政变）配指标：高级将领异常调动、军队通信加密升级、边境部队回撤首都、官方媒体口径变化、外国使馆撤离演练。每月采集 → 档案比对 → 若 3 个以上指标触发则升级预警。指标未触发时，避免"政变不可避免"的过度推断。

## 适用场景 (When to Use)
- **何时使用**：需跟踪特定情形随时间变化；与情景配对识别哪个正在形成；监控政治不稳定、经济改革等动态。
- **适合的问题类型**：需持续监控的动态局势；战略预警问题。
- **团队还是个人**：个人或团体均可。
- **预期产出**：一份指标清单（搜集指南 + 监控系统）。

## 对抗的认知偏见 / 核心价值
作为情报分析最古老的实证形式，其核心价值是**以客观、预先设定的清单取代数据缺口下的直觉推理**——当信息不全时，分析人员易依赖心理捷径（可得性、代表性）做判断；指标清单把判断锚定在可观察、可验证的事实序列上。同时克服**后见之明偏见**：清单在工作初期就记录了真实思考，防止事后重构"我早知道"。预期指标未出现时，还能减弱"假定某些事不可避免"的偏见。

## 与其他方法的关系
与几乎所有情景方法密切配对；是若则分析法和高影响/低概率分析法的基础；在竞争性假设分析法中指标常以证据形式出现；其诊断力不足的缺陷须由指标验证因子法™（3.6）补足。

## Anti-patterns / 潜在缺陷
- **诊断力不足**：同一指标可能与多个不同结果吻合，单独看价值有限。
- 脱离情景使用——指标失去语境即失去意义。
- 搜集不一致，可靠性崩塌。

## Key Takeaways
- 情报分析最古老的形式
- 指标只在情景中才有意义
- 预先承诺对抗后见之明
- 清单指导搜集与档案
- 须配 3.6 验证诊断力
