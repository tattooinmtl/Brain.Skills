# 4.1 — 简单假设法（Simple Hypothesis）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第四类 假设生成与检验
**编号**：4.1
**创始人/来源**：伦道夫·弗森（Randolph Pherson）开发

## Core Idea
低门槛、高实用性的假设生成方法，适合分析项目启动阶段。通过召集背景多样化团队、运用结构化头脑风暴，"广度优先"快速生成涵盖多种可能性的替代假设，避免分析人员在项目初期就锁定单一解释路径。

## Framework / Mental Model
- **好假设五标准**：①明确陈述而非问题；②以观察和知识为基础；③可被检验和证伪；④能明确预测预期结果；⑤包含因变量与自变量两个要素。
  - When to use: 评估生成假设质量时
  - How: 逐条比对清单打钩
- **创造性思考三途径**：情势逻辑法（基于已知事实与基础性力量推理）、历史类比法（参考同类案例）、理论法（从系统性知识获取洞见）。

## Key Concepts
- **替代假设清单**：最终产出，应力求假设间相互排斥、列表尽可能全面。
- **广度优先**：先求覆盖面，再求深度。
- **团队多样性**：不同专业知识、文化知识、利益视角、思维类型。
- **对抗认知偏见**：锚定效应（anchoring on first plausible hypothesis）——通过强制生成多个起点，防止首个看似合理的假设占据主导。
- **5W1H 阐明**：用何人/何事/何时/何地/为何/如何澄清每个假设。

## 操作步骤 (Procedure)
1. 定义问题，明确假设用途（情景设计基础、ACH 输入、筛选手段）。
2. 召集多样化背景团队。
3. 每人在卡片上写 3 个替代解释/假设（三途径激发）。
4. 回收卡片，白板汇总，合并重复项。
5. 头脑风暴识别关键力量/因素。
6. 假设归入相似组，每组贴标签。
7. 用问题重述和逆向思维提出新观点。
8. 更新清单；若供 ACH 使用，保持假设排他性。
9. 用 5W1H 阐明每个假设。
10. 选出最有可能以预期方式发展的假设做深入探究。

## Worked Example
分析某国突然军事演习：团队 6 人各自写 3 张卡片，汇总后合并为 8 条（例行训练、威慑邻国、掩护兵力调动、领导人健康状况转移视线、装备测试、联盟协同演练、应对内部动乱、欺骗行动）。归为 3 组：常规、信号性、内部驱动。最终挑出"威慑邻国"和"掩护兵力调动"送入 ACH。

## 适用场景 (When to Use)
- **何时使用**：项目启动阶段，需拓宽合理假设范围时；课题重要性高、变量多、结果不确定时；分析人员/决策者观点相互矛盾时。
- **适合的问题类型**：解释过去事件或判断未来发展的情报问题。
- **团队还是个人**：团队方法，需多样化人员参与以确保观点广度。
- **预期产出**：一份经过合并和归类的替代假设清单。

## 对抗的认知偏见 / 核心价值
- **锚定效应**：强制在锁定前生成多条替代路径，防止首因效应占据主导。
- **过早下结论**：用清单形式迫使分析人员考虑多个竞争性解释。
- 核心价值：作为 ACH、情景分析、论证图示法等下游方法的入口。

## 与其他方法的关系
生成的假设清单可作为 **4.5 ACH**、**第五章情景分析法**、**4.6 论证图示法** 的输入；与维恩分析、结构化头脑风暴、星爆法、德尔菲法、决策树法互补。

## Anti-patterns / 潜在缺陷
- 团队构成单一或思维受限 → 生成的假设清单出现盲区。
- 头脑风暴被少数声音主导，丧失多样性红利。

## Key Takeaways
- 广度优先，深度其次
- 多样化团队是关键
- 假设须互相排斥
- 用 5W1H 阐明
- 作为 ACH 的入口

## Connects To
- **4.5 ACH**：本方法生成的假设清单直接喂入 ACH 矩阵。
- **4.2 多种假设生成程序法™**：当简单假设法产出的清单被某个首选假设主导时，升级到 4.2 进行分解重组。
- **范式 Ⅲ 证伪主义**：生成多个可证伪假设是证伪流程的第一步。
