# 7.2 — 结构化辩论法（Structured Debate）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第七类 冲突管理
**编号**：7.2

## Core Idea
在观众与评判组面前进行的预先计划的正式辩论，其核心规则是各方必须反驳对方论据，而非不断追加支持己方的证据。胜方是反驳对方最有力的一方。源于苏格拉底式对话，由霍耶尔整理为情报分析体系。

## Framework / Mental Model
- **反驳优先规则（Refutation-First Rule）**：评分不看谁支持己方最有力，而看谁驳倒对方最有力。
  - When to use：对抗性协作失败，或对立观点必须二选一时
  - How：将冲突设计为互相排斥的假设 → 各方提交书面论据 → 当庭互相反驳 → 评判组裁定
- **穆勒原则**：只知己方观点的人，对论据所知甚少——必须经过被反驳的考验。

## Key Concepts
- **互相排斥的假设**：冲突必须可被框定为二者择一，确保辩论聚焦。
- **评判组（peer panel）**：由同行专家、高级分析员或管理人员组成的中立方。
- **书面论据先行**：口头辩论前先交换书面陈述，留出准备反驳时间。
- **A 队/B 队法**：情报界类似实践，但本方法更强调反驳而非简单分团。
- **无法驳倒的处理**：若双方均无法驳倒对方，则两种观点都应记入最终报告。

## 操作步骤 (Procedure)
1. 阐明冲突，按互相排斥的假设设计辩题，双方对界定无异议。
2. 为每个假设指定能提出最佳论据的个人/团队。
3. 各方撰写书面论据：明确关键假定、关键证据、逻辑链条。
4. 交换书面论据，留出准备反驳的时间。
5. 评判组与观众在场，正式辩论开始：
   - 各方陈述己方立场论据（≤5 分钟）。
   - 各方反驳对方书面论据（口头重点在驳倒替代假设，而非补充己方证据）。
   - 一方反驳后，另一方有权回应。
6. 评判组提问澄清。
7. 评判组讨论并裁决：获胜方是反驳对方最有力者。

## Worked Example
辩题："X 国领导人是否已下令军事行动？" A 队（支持假设）提交书面论据依据截获通信；B 队（反对假设）提交论据依据部队调动模式不符。辩论环节：A 队反驳 B 队——指出调动模式有 3 周滞后；B 队反驳 A 队——指出通信术语存在歧义、可解读为演习。评判组裁定 B 队胜，因通信歧义被实质性驳倒而调动解释未完全成立，建议情报搜集进一步核实术语。

## 适用场景 (When to Use)
- 分析单位内部、单位之间或决策层内部意见分歧严重。
- 长期政策问题、具有深远影响的关键决策。
- 对抗性协作不成功或不切实际，但必须在两种对立观点间做出选择。
- 妨碍机构间有效协作的长期分析争论。

## 对抗的认知偏见 / 核心价值
**团体迷思 / 论据简化**：常规讨论中，能言善辩者让薄弱观点听起来更有说服力，群体则倾向于附和。结构化辩论强制把评分焦点从"谁说得好"转移到"谁驳得倒"，反制口才偏见；同时强制反驳规则要求每一方真正消化对方论据，反制团体迷思。

## 与其他方法的关系
是 **7.1 对抗性协作法** 的升级路径——当协作无法达成时转为辩论裁决。

## Anti-patterns / 潜在缺陷
- 参与者例行公事般打断、不消化对方发言即开始反驳，沦为情绪化口水仗。
- 能言善辩者可能让弱观点显得有说服力——评判组需警惕口才偏差。
- 耗费大量分析时间和资源。

## Key Takeaways
- 反驳对方 > 支持己方——这是评分规则的核心反转。
- 冲突必须设计为互相排斥的假设。
- 评判组裁决依据反驳力度，而非论证丰富度。
- 无法互相驳倒时，两种观点都进报告。

## Connects To
- **7.1 对抗性协作法**：互补关系，协作失败 → 升级为辩论。
- **A 队/B 队法**：情报界类似实践，但本方法更强调反驳规则。
- **竞争性假设分析法（ACH）**：同样追求"最少反对证据"的假设，但 ACH 是单人/团队分析工具，结构化辩论是冲突裁决工具。
