# 1.4 — 问题再定义法（Issue Redefinition）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第一类 分解与可视化
**编号**：1.4

## Core Idea
一个问题的表述方式看似差别很小，却对研究方向产生巨大影响。问题再定义法提供六种策略强制重构问题表述，防止"任务蠕变"（mission creep）——即由于问题过于复杂或分析员理解不充分，分析方向无意中偏离核心情报问题。

## Framework / Mental Model
- **六重重构策略**：改述 / 问为什么 / 扩大焦点 / 缩小焦点 / 转移焦点 / 反转角度
  - When to use: 课题开始时；分析过程中新假设或新证据出现时；思考停滞时；防任务蠕变时
  - How: 六种策略不分先后，任选一种或多种对原问题进行重构，对比新表述是否能更好指导研究

## Key Concepts
- **任务蠕变（Mission Creep）**：分析方向无意中偏离核心情报问题的现象
- **改述（Paraphrase）**：不丧失原意地重新表述问题
- **扩大/缩小焦点**：后退一步看更宏观背景，或将问题细分为子问题
- **反转角度**：从相反方向提问，如"参战的有多少"改为"不参战的有多少"
- **协作重构**：使用维基等公开共享工具协作完成重构时最高效

## 操作步骤 (Procedure)
以下六种策略不分先后，可激励分析员采用新的或不同的思考方式阐明问题：
1. **改述（Paraphrase）**：在不丧失原意下重新定义问题。例：原问题"昂山素季在当前缅甸动荡中发挥了多大作用？"→ 改述为"昂山素季领导的民盟在缅甸反政府骚乱中有多活跃？"
2. **问为什么（Ask Why）**：针对问题定义提出一系列"为什么"或"怎么样"。第一次回答后继续追问，持续提问直到真正的问题显现。在生成替代答案方面非常高效。
3. **扩大焦点（Expand Focus）**：不纠缠某一点，后退综合考虑多方面。例："巴基斯坦总统有多腐败？"→"整个巴基斯坦政府有多腐败？"
4. **缩小焦点（Narrow Focus）**：将问题进一步细分，对构成难点的各部分分别提问。例："欧盟会继续支持欧元吗？"→"欧盟各成员国怎么看待欧元？"
5. **转移焦点（Shift Focus）**：考虑外界因素，判断是否与欺骗有关。例："基地组织引起的恐怖威胁已急剧减少了吗？"→"基地组织各分支现今对美最大威胁是什么？"
6. **反转角度（Reverse the Angle）**：从相反方向考虑。例："首轮攻台中解放军参战地面部队有多少？"→"不参战的地面部队有多少？"

## Worked Example
**from source**: 原问题——"巴基斯坦总统有多腐败？"采用"扩大焦点"策略扩展为"整个巴基斯坦政府有多腐败？"——这一重构把焦点从单一人物转移到系统性问题，使分析能够纳入部长级、军方、司法等多个层级的腐败指标，避免结论被单个领导人的形象所主导。

## 适用场景 (When to Use)
- **何时使用**: 课题开始时帮助顺利迈出第一步；分析过程中任何时间节点当新假设或关键新证据出现时；当分析员思考停滞不前时；防止任务蠕变时
- **适合的问题类型**: 初始问题定义不清晰、过于模糊或可能误导分析方向的情报问题
- **团队还是个人**: 个人或团体均可，使用维基等协作工具时最有效率
- **预期产出**: 一个或多个经过重新定义的问题表述，为后续分析提供更准确的研究方向

## 对抗的认知偏见 / 核心价值
作为范式 Ⅳ 流程工具，问题再定义对抗的核心偏见是**锚定效应**——分析员被初始问题表述锁定，所有后续思考围绕原始措辞展开，即使该措辞本身有缺陷。六种策略通过强制从不同角度重构问题，打破初始锚定。另一个对抗的偏见是**框架效应**：同一问题以不同方式表述会引导完全不同的结论。该方法也被称为"问题发展"（Issue Development）、"问题重述"（Problem Restatement）、"重构问题"（Reframing the Question）。

## 与其他方法的关系
常与 1.1 启动清单法、1.3 用户清单法同时使用。重构后的问题方向应与用户或委托方确认，避免偏离原始需求。

## Anti-patterns / 潜在缺陷
- **过度重构**：无特定方法论缺陷，但过度重构问题可能导致分析方向偏离委托方的原始需求。因此重新定义问题后应与用户或委托方确认新方向是否被认可

## Key Takeaways
1. 问题表述的小差异带来研究方向的大偏离
2. 六策略中"问为什么"和"反转角度"最具颠覆性
3. 思考停滞时，重构问题比硬想答案更有效
4. 用维基协作重构，效率最高
5. 重构后必须与委托方确认方向，避免南辕北辙

## Connects To
- **1.1 启动清单法**: 启动清单第 2 步"界定关键问题"通常需调用问题再定义
- **1.3 用户清单法**: 用户清单第 3 题"用户问对问题了吗"的解决工具
- **范式 Ⅳ**: 用流程化重构策略对抗锚定效应，而非依赖灵感
- **波普尔证伪主义**: "反转角度"策略暗合证伪思想——主动寻找反方向证据
- **5 Whys 丰田方法**: "问为什么"策略与丰田 5 Whys 根因分析法同源
