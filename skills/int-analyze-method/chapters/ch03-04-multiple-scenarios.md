# 3.4 — 多种情景生成法（Multiple Scenarios Generation）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第三类 情景与指标
**编号**：3.4

## Core Idea
与替代前景分析法（3.3）极为相似，唯一不同是**不必局限于 2 个关键驱动力**。通过多个 2×2 矩阵对所有驱动力两两配对，可生成大量可能情景。目的是**确保不漏掉任何可能的情景**——一旦分析人员对这些情景变得敏感，就能注意到那些外围但显示事件正以未想象方式发展的数据，**极大降低事情向未预测方向演变的概率**。

## Framework / Mental Model
- **多矩阵配对（Multiple 2×2 Matrices）**：N 个驱动力 → C(N,2) 个 2×2 矩阵 → 海量情景 → 筛选。
  - When to use：关键驱动力超过 2 个；需穷尽可能性时。
  - How：选最难预测的因素为驱动力 → 多矩阵配对 → 每象限 1–2 情节 → 筛选关注集 + 指标。
- **筛选机制**：从大量情景中选出最值得关注的、阐明尚未被考虑的未来。

## Key Concepts
- **驱动力选取标准**：结果最难预测、或分析人员不能自信评估的因素。
- **创造性思维专家**：团队成员应包括能质疑既有思维模型的人。
- **外围数据敏感性**：核心价值——让人注意到原本忽略的早期信号。
- **筛选环节**：时间和复杂性约束下的必要过滤。
- **对抗思维定式（mindset / fixed mental model）**：穷尽配对打破单一框架。

## 操作步骤 (Procedure)
1. 明确定义焦点问题与未来运用目标。
2. 召集专家团体（含能质疑思维模型的创造性思维专家），头脑风暴可能左右问题走向的力量与因素。
3. 选出**结果最难预测、或分析人员不能自信评估**的因素作为驱动力。
4. 确定每个驱动力谱系的两端。
5. 在一系列 2×2 矩阵中对这些驱动力两两配对。
6. 为每个 2×2 矩阵的每个象限形成 1–2 个情节。
7. 从所有生成情景中，选出那些最值得关注的、阐明尚未被考虑的未来。
8. 形成并验证能跟踪每个情景是否正在发展的指标。
9. 定期就哪个情景正在形成及原因进行报告。

## Worked Example
**from source**：研究"伊拉克国内叛乱的前景"。识别 4 个驱动力：教派关系、安全部队能力、外部势力、经济状况。两两配对生成 6 个 2×2 矩阵 = 24 个象限情景，每象限 1–2 情节，最终筛选出 5–6 个最值得关注情景，各配指标清单，按月跟踪报告。

## 适用场景 (When to Use)
- **何时使用**：关键驱动力超过 2 个；大型战略前瞻课题；需确保不遗漏任何可能情景时。
- **适合的问题类型**：高度复杂、多驱动力相互作用的长期预测。
- **团队还是个人**：专家组团体，需经验丰富的指导人员；可能需数天。
- **预期产出**：大量情景（多矩阵生成），经筛选后附指标。

## 对抗的认知偏见 / 核心价值
对抗**思维定式**——分析人员常锁定一个心理模型并据此过滤信息。通过穷尽所有驱动力的两两配对，本方法强制暴露那些不符合既有模型的组合，让人对"外围但真实"的信号变得敏感，从而极大降低事件向未预测方向演变的概率。核心价值是穷尽性带来的认知去盲。

## 与其他方法的关系
替代前景分析法（3.3）的扩展版（解除 2 驱动力限制）；下游必接指标法（3.5）与指标验证因子法™（3.6）以筛选和验证监控点。

## Anti-patterns / 潜在缺陷
- 使用前未培训、无经验丰富的指导人员——产出失控。
- 缺乏有效筛选机制，淹没在海量情景中。
- 驱动力选取不当（选了可自信评估的因素），失去穷尽意义。

## Key Takeaways
- 解除 2 驱动力限制
- 多矩阵配对穷尽可能
- 需创造性思维专家
- 筛选环节必不可少
- 对抗思维定式
