# 2.3 — 名义团体法（Nominal Group Technique, NGT）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第二类 观点生成
**编号**：2.3

## Core Idea
名义团体法（NGT）与结构化头脑风暴目标相同（生成创新、可行观点）但路径迥异：**以循环方式每次每人只提一个观点**，循环至穷尽。其核心价值是**防止讨论受个人操控**——当资深官员或强势成员可能左右方向、资浅成员不敢发言、或问题争议激烈时，NGT 是首选。

## Framework / Mental Model
- **NGT 循环提交—讨论—投票三段式**
  - When to use: 权威人士出席；资历差异大；争议性议题
  - How: 静默写卡 → 循环每次一人一观点 → 逐条讨论（禁支持/反对论述）→ 不记名投票排序

## Key Concepts
- **循环提交**：主持人每次邀请一人提出一个观点，循环至穷尽，禁讨论。
- **不记名投票**：通常按每3个观点投1票的比例，或1–5分排序制表。
- **有限观点清单**：NGT 聚焦数量有限、经过慎重排序的看法，区别于头脑风暴的量大。
- **专注他人观点**：参与者专注被提观点本身而非构思自己发言，鼓励整合、修改、扩展。

## 操作步骤 (Procedure)
1. 主持人提出开放式问题（如"什么因素将影响……？"）。
2. 参与者不公开在卡片记下初步看法（5–10分钟）。
3. **循环提出观点**：每次邀请一人提一个，挂图/白板写下简要概述，循环至穷尽，禁讨论。
4. **讨论阶段**：按观点顺序逐一讨论，确保共同认识；不允许支持或反对的论述；可扩展或整合。
5. **投票排序**：不记名投票，每3个观点投1票；或每人写5个最佳并1–5分排序，主持人制表公布。
6. 如需，第二轮投票对前3–5名排序。

## Worked Example
**示意**：评估"Y国政变可能性"，局长列席。8名分析师静默写卡8分钟，循环提交得27条；局长无法抢先定调。逐条讨论整合为19条；不记名投票（每人投6票）后前5项入清单，包含2名初级分析师贡献的关键指标。

## 适用场景 (When to Use)
- **何时使用**: 防止讨论受个人操控；争议性问题；权威人士出席。
- **适合的问题类型**: 需平等参与的观点生成与决策问题。
- **团队还是个人**: 团体（强调平等参与）。
- **预期产出**: 一份经投票排序的有限观点清单。

## 对抗的认知偏见 / 核心价值
直接对抗**权威压制**与**讨论操控**——资深成员抢先发言会左右方向、资浅者噤声。循环提交+不记名投票的结构强制平等参与，让每个观点按其价值而非发言者地位被评估。

## 与其他方法的关系
与 **2.1 结构化头脑风暴**、**2.2 虚拟头脑风暴** 功能相似但路径不同；NGT 聚焦有限慎重观点，头脑风暴追求数量最大化。

## Anti-patterns / 潜在缺陷
- 比头脑风暴更正式、更耗时。
- 不适合需要大量发散观点的场合。

## Key Takeaways
1. 循环提交杜绝垄断发言
2. 不记名投票剥离权威
3. 专注他人观点而非自辩
4. 重质量与排序非数量
5. 争议性议题首选

## Connects To

- **2.2 虚拟头脑风暴**: 远程变体的并行选项。
