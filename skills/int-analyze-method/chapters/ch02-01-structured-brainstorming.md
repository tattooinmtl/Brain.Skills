# 2.1 — 结构化头脑风暴（Structured Brainstorming）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第二类 观点生成
**编号**：2.1

## Core Idea
结构化头脑风暴不是一群人围坐闲谈，而是遵循明确规则、由主持人协调、配合安静思考与即时贴的团体程序。其核心价值在于让分析人员一次会议内接触到远超独自思考的视角广度，从而拓展视野、产出更好的分析产品。

## Framework / Mental Model
- **Osborn–Pherson 结构化头脑风暴框架**：发散（量不质评）→ 沉默（异类种子）→ 趋同（按群聚类）→ 排序（多标准投票）
  - When to use: 课题初期确定变量、驱动力、假设、参与者、证据清单
  - How: 严格的两阶段（发散/趋同）+ 5–7人最佳规模 + 至少5个判断标准排序

## Key Concepts
- **沉默的头脑风暴**：每人安静5分钟在卡片上写下关键观点，避免抢话。
- **等待沉默**：观点减缓时1分钟停顿不打断，新见解常在此时浮现。
- **异类即时贴**：不属于任何聚类的卡片，往往是新观点的种子。
- **团体迷思**：本方法重点对抗的偏见，吸纳局外人稀释一致性压力。
- **重视第一手信息**：直觉陷阱，头脑风暴通过强制接触多元观点来中和。

## 操作步骤 (Procedure)
1. **会前准备**：明确目的，提前宣布主题，要求带着观点参会。
2. **组建团队**：4–12人（5–7最佳），超12人分组；吸纳1名以上局外人。
3. 主持人介绍焦点问题与基本规则。
4. **发散阶段**：自由提出所有观点；可用"沉默的头脑风暴"5分钟写卡。
5. 用白板、黑板架或即时贴记录全部讨论。
6. **等待沉默**：观点减缓时1分钟停顿不打断。
7. **趋同阶段**：将即时贴按意思相近分组排列（按群非行列），不允许讨论；关注"异类"。
8. 为每组选出描述性词或短语。
9. **评估优先**：建立至少5个判断标准，用排序投票法区分优先次序。
10. 总结并通过维基网站分发。

## Worked Example
**示意**：分析"未来12个月影响X国政局的因素"。5名分析师各安静5分钟写卡，共得42张。聚类后形成6群（经济、军方、反对派、外部势力、宪政、社会运动），1张异类聚焦"水短缺"。投票后前5项进入交叉影响矩阵分析。

## 适用场景 (When to Use)
- **何时使用**: 课题初期定变量/驱动力/假设；分析后期将团队从定式中拉出。
- **适合的问题类型**: 开放性问题，如"哪些因素有助于解释……"。
- **团队还是个人**: 团体（5–7人最佳），需主持人。
- **预期产出**: 一份经排序的观点清单，可供后续方法使用。

## 对抗的认知偏见 / 核心价值
重点对抗**团体迷思**与**重视第一手信息**直觉陷阱——人们倾向只关注强化第一印象的新信息而忽视缺失信息。强制多元视角与局外人参与，让缺失变量浮出水面。

## 与其他方法的关系
后续常接 **2.5 交叉影响矩阵法** 检查变量间关系；担心资深成员左右会议则改用 **2.3 名义团体法**。

## Anti-patterns / 潜在缺陷
- 时间不足：通常需1小时左右才能催生创造性观点。
- 主持人失控：讨论偏离、资深者垄断发言都破坏流程。

## Key Takeaways
1. 结构化 ≠ 自由讨论
2. 沉默期是新观点温床
3. 异类卡片是创新种子
4. 局外人稀释团体迷思
5. 至少5标准排序投票

## Connects To
