# 6.3 — 若则分析法（What If? Analysis）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第六类 质疑分析
**编号**：6.3

## Core Idea
假设某个重大事件**已经发生**，然后从未来逆向回溯到今天，解释它是怎么发生的。这一重构让大脑从"会不会发生？"的犹豫，切换到"既然发生了，原因是什么？"的求解模式，从而打开原本封闭的思维路径。

## Framework / Mental Model
- **《纽约时报》昨天报道框架**：用"据《纽约时报》昨天报道，X 事件已经发生……"开场，强制进入"已发生"情境。
  - When to use: 分析界/决策者普遍认定某事"不会发生"时；某关键假定开始动摇；争议事件无人愿规划应对。
  - How: 假设事件已发生 → 逆推至少一条连贯因果链 → 为每链设指标监控。

## Key Concepts
- **逆向思维（Backward Reasoning）**：从未来终点倒推每一步必须为真的环节。
- **重构法（Reframing）**：把"是否发生"问题改为"如何发生"问题，切换认知模式。
- **多重情景**：至少生成两条以上因果链，避免单一剧情绑架。
- **可观察点（Observables / Indicators）**：每条情景配备指标，用于判断事态是否正沿该路径发展。
- **对抗思维定式 / 单一路径推理**：当"不会发生"成为集体信念时，只有假设它已发生，才能撬开这条神经回路。

## 操作步骤 (Procedure)
1. 头脑风暴确定要推演的"已发生"事件（用"据昨天报道……"句式）。
2. 清晰描述事件本身及其影响，必要时指定触发事件。
3. 在证据与逻辑基础上，构造至少一条连贯因果链——重点标出每个阶段"什么必须为真"。
4. 逆向推演，尽量生成不止一条路径。
5. 为每条情景设计指标/可观察点。
6. 评估负面后果严重度、缓解难度，或积极机会的实现条件。
7. 按关注度、可行性、影响排序情景。
8. 定期监控指标，报告情景是否正在成形。

## Worked Example
**场景**："据《纽约时报》昨天报道，A 国与 B 国宣布结成军事同盟。"逆向回溯——
- 路径一：A 国新政府上台 → 双方贸易摩擦骤降 → 联合军演 → 共同防御条约。
- 路径二：第三方 C 国威胁升级 → A、B 同时感到被挤压 → 安全需求压倒历史恩怨 → 秘密谈判 → 公开结盟。
- 指标：A 国新元首对 B 国表态、贸易争端解决速度、联合军演频次、C 国军力部署。
→ 即使团队主流认为"不可能"，仍能向决策者提供提前准备的应对方案。

## 适用场景 (When to Use)
- 分析界或决策者中"某事不会发生"的思维模型根深蒂固。
- 关键假定检查发现某核心假定可能站不住脚。
- 低概率但一旦发生后果严重的事件。
- 争议激烈但无人规划应对措施的问题。

## 对抗的认知偏见 / 核心价值
- **思维定式（Mental Set）**：一旦认定"不可能"，所有后续推理都在强化这个结论。"假设已发生"是撬动这种定式的最有效杠杆。
- **单一路径推理（Single-Path Reasoning）**：人倾向只顺着一条因果链思考。要求生成多条路径，强制扩展。
- **现状偏见（Status Quo Bias）**：默认未来是现在的延伸。"已发生"框架打破这一默认。
- 核心机制：和 Pre-mortem（6.1）同属"时间反转"家族，但 Pre-mortem 反转的是"我方方案的成败"，What If 反转的是"外部事件的是否"。

## 与其他方法的关系
与高影响/低概率分析法（6.4）常被混淆。区别：What If 用重构法**假设事件已发生，逆向推理**；高影响/低概率法需要**新的或异常信息作为触发**，然后**正向预测**后果。二者可串联使用。

## Anti-patterns / 潜在缺陷
- 设计的情景常含高度敏感数据（如袭击路径、政变方案），需严格控制分发——越"高明"越易泄露。
- 概率表达不严谨：必须用数字范围（如 5–15%）而非"不太可能"等模糊词。
- 只生成一条路径，仍是单线推理。

## Key Takeaways
- 用"据昨天报道……"开场，是最简单的认知开关。
- 重点不在事件本身，而在"每个阶段什么必须为真"的逆向链条。
- 多路径 + 指标监控，把质疑成果转化为可追踪的预警体系。
- 是每个分析人员都该掌握的常备工具，而非偶用技法。
- 与 6.4 的关键区别：逆向推理 vs 正向预测。

## Connects To
- **6.1 事前分析法**: 同为时间反转家族，Pre-mortem 反转内部方案，What If 反转外部事件。
- **6.4 高影响/低概率分析法**: 同处理低概率事件，但推理方向相反，可互补。
- **关键假定检查（外部方法）**: 当某关键假定动摇，What If 是其逻辑后续——"假定错了会怎样？"
- **情景分析法（外部方法）**: What If 是其简化变体，区别在于"已发生"的假设框架。
