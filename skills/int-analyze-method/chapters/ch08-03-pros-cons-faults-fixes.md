# 8.3 — "赞成-反对-错误-纠正"法（Pros-Cons-Faults-and-Fixes）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式 ⚠️ **范式离群点**——决策支持类 7 种方法中唯一属于范式 Ⅲ 者，其余 6 种（8.1/8.2/8.4/8.5/8.6/8.7）均为范式 Ⅱ（量化/系统）。此差异源于本方法的证伪内核：主动寻找己方论据的错误。
**方法类别**：第八类 决策支持
**编号**：8.3

## Core Idea
为避免对提案过早附和或过早否定，先列"赞成"与"反对"清单，然后**单向深度分析**：若团队偏消极，寻找每个"反对"的"纠正"措施；若团队偏乐观，挑出每个"赞成"的"错误"。这是所有决策支持法中最快、最易用的。

## Framework / Mental Model
- **方向性证伪（Directional Falsification）**：根据团队倾向选择证伪方向——消极时证伪"反对"（找纠正），乐观时证伪"赞成"（找错误）。
  - When to use：评估新政策理念、两选项快速比较、团队存在过度乐观或过度消极倾向时
  - How：列赞成 → 列反对 → 选向 → 单向深挖 → 专业判断（非投票/分数）
- **摩根·琼斯原版 + 霍耶尔增维**：原版仅赞成/反对；霍耶尔补"错误/纠正"维度，使方法具备证伪能力。

## Key Concepts
- **赞成（Pros）**：提案的益处与优势——广泛、创造性列举。
- **反对（Cons）**：提案的缺陷与阻力——通常多于赞成（人天生批判倾向）。
- **纠正（Fixes）**：对每个反对的化解——修订建议、预防措施、应急计划、研究需求。
- **错误（Faults）**：对每个赞成的证伪——不成立的论据、不希望的副作用、研究需求。
- **专业判断原则**：最终决策基于专业判断，**禁止**用加权总分决断——任何数值都可被增减项操控。
- **不对称应用**：单次会议只走"纠正"或"错误"一个方向，依据团队倾向选择反偏压方向。

## 操作步骤 (Procedure)
1. 明确界定拟议的行动或选择。
2. 列出"赞成"——广泛、创造性，尽可能多。
3. 列出"反对"——通常多于赞成。
4. 审查并合并近似或重复项。
5. 若是两选项决策，对第二选项重复 1-4。
6. **判断团队倾向，选向深挖**：
   - 团队消极 → 找每个"反对"的"纠正"（修订/预防/应急/研究）。
   - 团队乐观 → 挑每个"赞成"的"错误"（不成立论据/副作用/研究）。
7. 综合权衡赞成与反对清单，做专业判断。
8. 最终选择依专业判断，**非票数或分数**。

## Worked Example
提案：进入 Z 国市场。赞成：增长潜力大、先发优势、品牌扩展。反对：法规风险高、文化差异、资本占用大。团队氛围过于乐观（CEO 力推）。选"挑赞成错误"方向：增长潜力大？——实际人口结构下行，增长预测基于过时数据；先发优势？——本地巨头已占 70% 份额，先发实为后入；品牌扩展？——跨品类稀释风险。结论：赞成项多不成立，建议暂缓进入并补做人口与竞品调研。

## 适用场景 (When to Use)
- 需快速评估新观点或从两选项中做出选择。
- 团队存在过度乐观或过度消极倾向——用反向深挖反偏压。
- 新政策理念的早期评估。
- 选项 ≤ 2 的快速比较。

## 对抗的认知偏见 / 核心价值
**二元简化**：单纯的赞成/反对清单会遗漏关键事实——许多"反对"是**可纠正的**，许多"赞成"是**站不住的**。PCFF 通过强制单向深挖，反制"二元清单 = 完整分析"的错觉。这是其被归入证伪主义范式 Ⅲ 的根因——主动寻找己方立场的可证伪点。

## 与其他方法的关系
选项超过两个时改用 **8.2 决策矩阵法**。商业领域可用于评估新产品或收购时的潜在缺陷发现。

## Anti-patterns / 潜在缺陷
- **禁止加权赋值总分决断**——任何数值都可通过增减项操控，必须依专业判断。
- 单向深挖方向选错（与团队偏向同向）会放大偏见而非反制。
- 团队倾向判断本身可能主观——建议由中立主持人裁定倾向。

## Key Takeaways
- 赞成 + 反对 + 错误 + 纠正 = 四维清单，**单向**深挖。
- 方向选择反团队偏向：消极找纠正，乐观挑错误。
- 最终依专业判断，绝不用加权分数。
- 范式 Ⅲ 离群点——证伪内核区别于决策支持类的其他 6 种范式 Ⅱ 方法。

## Connects To
- **8.2 决策矩阵法**：选项 > 2 时的升级路径。
- **关键假定检查法**：同属范式 Ⅲ，亦主动质疑己方假定。
- **红帽分析法**：可借用其视角评估提案的赞成与反对。
