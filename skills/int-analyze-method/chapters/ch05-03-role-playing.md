# 5.3 — 角色扮演法（Role-Playing）

**范式归属**：范式Ⅲ：认知心理学/证伪主义范式
**方法类别**：第五类 因果评估
**编号**：5.3

## Core Idea
冲突形势本质上是一连串"行动—反应—再反应"的互动链，而人脑并不具备推演这种复杂互动的认知能力。角色扮演法通过让分析人员**持续扮演**外国领导人或利益相关方，对情景做出真实反应，从而模拟出单凭推理无法触及的动态。研究数据令人印象深刻：在 143 次预测中角色扮演的准确率达 56%，而无辅助专家在 172 次预测中仅 16%。核心原则只有一句——"演活"角色，从角色本人的视角行事，而不是从分析师的"上帝视角"去想象。

## Framework / Mental Model
- **持续扮演—互动推演—事后审查模型**：情景刺激 → 角色第一人称反应 → 多方互动 → 关键转折点 → 替代行动
  - When to use: 需要理解两个及以上行为主体相互影响时的动态（冲突、谈判）
  - How: 离场闭关 → 一人一角 → 导调组监控 → 事后审查关键转折点

## Key Concepts
- **持续扮演 vs. 上帝视角**：参与者必须真正像角色本人那样行事，从角色的"屁股"决定"脑袋"，而非分析师的鸟瞰
- **行动—反应链**：冲突形势的本质——每一次行动都取决于另一方对己方前次行动的反应
- **关键转折点**：决定推演演进方向的少数决策节点，事后审查的重点
- **轻装快速**：与军事推演不同，几乎不需要事先准备，常在一两天内完成
- **"副产品"效益**：将分析人员聚到一处面对面交流，带来长期协作价值
- **导调组职责**：监控时间、传递信息、组织事后审查、必要时加入新事件引导方向

## 操作步骤 (Procedure)
1. 安排在办公地点之外进行，要求关闭手机——远离办公室有利于排除干扰，使参与者更容易代入角色。
2. 每名参与者只扮演一名外国领导人或利益相关方；可模拟国家内部决策或两国互动。
3. 保持团体规模在可管理范围，确保所有参与者都有活跃角色。
4. 由导调组负责监控时间、传递信息、组织事后审查；必要时加入新事件引导推演方向。
5. 推演结束后（或次日）进行事后审查——检查参与者是否因投入而高估推演结果为"现实预测"；导调组记录关键转折点，团体讨论每个转折点可采取的其他合理行动及其不同结果。

## Worked Example
**情景**：邻国 A 宣布对争议海域进行石油勘探许可招标，B 国需决定反应。

3 名分析人员分别扮演 A 国总统、B 国总理、A 国盟友 C 国领导人，导调组注入"勘探平台已抵达"的刺激。推演中，B 国扮演者选择驱逐舰对峙，A 国扮演者随即邀请 C 国"联合巡航"，C 国扮演者在"国内经济压力"与"同盟信誉"间犹豫，最终选择仅发表声明——这一转折点在事后审查中被识别为最关键的动态，B 国事先未预料到 C 国会退缩。结论：B 国的对峙策略风险被低估，C 国的实际支持承诺远低于公开姿态。

## 适用场景 (When to Use)
- **何时使用**：需要理解两个及以上行为主体相互影响时的动态（特别是冲突或谈判形势）；需要把分析人员聚到一起但之前缺乏面对面交流时。
- **适合的问题类型**：冲突预测；谈判策略分析；领导人决策模式分析。
- **团队还是个人**：团队，需导调组和角色扮演者。
- **预期产出**：对冲突形势可能演进方向的理解 + 对关键转折点和替代行动方案的分析。

## 对抗的认知偏见 / 核心价值
- **镜像思维（mirroring — assuming adversaries think like us）**——这是本方法的靶心。情报失误最常见根源就是无意识假定他国领导人会像我们一样行事；持续扮演强迫分析人员从"对手的屁股"思考，打破了这种镜像投射。
- **上帝视角谬误**：从分析师的鸟瞰视角推演互动，必然忽略角色在信息不完全、时间压力下的真实决策；"演活角色"恢复了这种限制。
- **静态思维**：把冲突视为一次性事件而非行动—反应链——互动推演暴露了动态复杂性。

## 与其他方法的关系
角色扮演法与红帽分析法互补——红帽侧重通过文化理解预测对手行为，角色扮演更侧重动态交互过程的模拟；它也是将分析人员聚集在一处的实用机制，可带来"副产品"式的长期协作效益。

## Anti-patterns / 潜在缺陷
- **高估推演结果为预测**：模拟结果对参与者思考的影响可能比案例的已知事实还要强烈，须由事后审查抵消。
- **角色刻板化**：扮演者套用"流行形象"而非真实人物的价值观与决策风格，沦为演戏而非分析。
- **错误率仍高**：虽比无辅助专家（16%）准确得多（56%），但目标应是更好理解形势而非做明确预测。

## Key Takeaways
- "演活角色"是核心原则——从角色的第一人称视角行事，而非分析师的上帝视角想象。
- 价值在动态而非静态——模拟行动—反应—再反应的链条，触及人脑无法推演的复杂互动。
- 事后审查必不可少——抵消参与者因投入而对推演结果产生的高估偏见。
- 目标是理解可能演进方向与关键转折点，不是做出明确预测。
- "副产品"效益不可忽视：把分析人员面对面聚到一起，本身就有长期价值。

## Connects To
- **红帽分析法 (5.4)**：互补关系——红帽重文化理解，角色扮演重动态交互
- **红队分析法**：本方法是"轻量级"版本，无须常设部门
- **关键假定检查法 (5.1)**：扮演角色时浮现的隐性假定，可回流至假定检查
- **简单情景法**：角色扮演产出的关键转折点可衍生情景分支
