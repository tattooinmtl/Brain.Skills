# 2.2 — 虚拟头脑风暴（Virtual Brainstorming）

**范式归属**：范式 Ⅳ：结构化协作/流程工具范式
**方法类别**：第二类 观点生成
**编号**：2.2

## Core Idea
虚拟头脑风暴是参与者异地时使用的结构化头脑风暴变体。其核心价值在于克服面对面交流中的"产生式阻碍"——发言需排队，等待者既要构思自己的内容又要关注发言者，常导致想法遗忘。匿名功能还可在身份敏感环境中收获"原生态观点"而非"政治上正确的观点"。

## Framework / Mental Model
- **同步/异步双模式框架**：同步（所有人与会实时）与异步（各自按情况提出）
  - When to use: 参与者分散异地；动用外界专家组；身份/地位会影响行为时
  - How: 选协作软件 → 在线公布焦点问题 → 在线发散 → 在线趋同分类排序

## Key Concepts
- **产生式阻碍（Production Blocking）**：面对面轮流发言导致想法遗忘的现象，本方法直接对抗之。
- **同步 vs 异步**：异步允许精神饱满时重温观点，往往生成更多新观点。
- **匿名观点**：身份或地位敏感时得到原生态而非政治正确的观点。
- **原生态观点**：剥离发言者身份后的真实想法，提升发散质量。

## 操作步骤 (Procedure)
1. 选择适当的协作软件平台（维基、在线白板等）。
2. 明确焦点问题并在线公布。
3. **发散阶段**：在线提出尽可能多观点，可同步或异步。
4. 利用软件上传文档、图表、照片或视频，共享观点。
5. **趋同阶段**：在线整理分类、淘汰、区分优先次序。
6. 所有讨论结果留存平台，供后续参考与修订。

## Worked Example
**示意**：跨国能源公司评估某国政权更迭风险，6名分布3洲的分析师在维基上异步提交观点，72小时内累积58条；匿名功能使初级分析师敢提出"国王健康隐患"这一资深者未敢明言的敏感点，最终进入优先清单。

## 适用场景 (When to Use)
- **何时使用**: 参与者分散不同地点；动用外界专家组。
- **适合的问题类型**: 同结构化头脑风暴（开放性问题）。
- **团队还是个人**: 团体（远程）。
- **预期产出**: 在线观点库，可持续追踪与修订。

## 对抗的认知偏见 / 核心价值
直接对抗**产生式阻碍**——面对面轮流发言使等待者一边构思自己内容一边关注发言者，想法易被遗忘。异步提交让每人精神饱满时贡献，匿名则剥离权威压制，捕获真实判断。

## 与其他方法的关系
与 **2.1 结构化头脑风暴** 和 **2.3 名义团体法** 功能相似，按地理位置和权威结构择优；面对面协同思维仍有优势。

## Anti-patterns / 潜在缺陷
- 缺少面对面接触，减少协同效应。
- 在线交流固有的延迟与媒介损耗。
- 需优秀主持人指导虚拟会议节奏。

## Key Takeaways
1. 异地首选，攻克产生式阻碍
2. 异步重温催生新观点
3. 匿名换原生态判断
4. 协同弱于面对面
5. 全程留痕可追溯
