# 4.2 — 多种假设生成程序法™（Multiple Hypothesis Generator™）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第四类 假设生成与检验
**编号**：4.2
**创始人/来源**：伦道夫·弗森（Randolph Pherson）开发

## Core Idea
专门应对"首选假设占绝对主导地位"的分析困境。突破点在于：不直接从零生成假设，而是将首选假设分解为"何人、何事、如何、何时、何地、为何"六个组成部分，对每个部分生成合理替代项，再通过排列组合生成全部可能的假设空间。借鉴波普尔证伪主义——质疑首选假设中隐含的各种假定。

## Framework / Mental Model
- **6W 分解 + 排列组合**：把首选假设拆为 6W，对每 W 生成替代项，全排列后过滤。
  - When to use: 首选假设占据绝对优势、需确保无遗漏时
  - How: 通常只 3 个 W 与问题直接相关；每 W 生成 3 个替代项即足够覆盖
- **1–5 分可信度评估**：为每个排列分配可信值，按最可信到最不可信排序。
- **好假设标准**：最终重述的假设须符合"明确陈述、可证伪、含因变量自变量"等。

## Key Concepts
- **首选假设**：占据分析人员或决策者心智主导地位的解释。
- **替代项**：每个 6W 维度上的其他合理取值。
- **排列爆炸**：组成部分过多 → 指数级爆炸，使分析失控。
- **隐含假定**：首选假设背后未经审视的预设，是发现"第四/第五种可能性"的关键。
- **对抗认知偏见**：证实偏见 + 假设空间狭窄——通过系统化排列强行打开假设空间。

## 操作步骤 (Procedure)
1. 定义待研究的问题/活动/行为。提问："要挑战首要假设，需要对定义做哪些变化？"
2. 快速列出首要假设中包含的假定的可能排列方案。
3. 按 6W 顺序分解首要假设（通常仅 3 部分直接相关）。
4. 针对每个关键组成部分生成合理替代项。
5. 审查各清单，确保替代项互相排斥。
6. 生成所有可能的排列清单。
7. 抛弃完全没有意义的排列。
8. 通过质疑每个组成部分的关键假定评估可信度，分配 1–5 分可信值。
9. 按最可信到最不可信排序。
10. 将排列重新陈述为符合"好假设"标准的假设。
11. 从清单顶部选出最值得关注的假设。

## Worked Example
首选假设"X 国军方发动政变"。分解 3 个关键 W：何人（军方/情报机构/反对派联盟）、为何（夺权/清剿异见/外部代理人行动）、如何（突袭首都/控制媒体/拉拢地方部队）。3×3×3 = 27 排列，抛弃无意义的 12 个，剩 15 个评分排序，顶部 3 个送入 ACH。

## 适用场景 (When to Use)
- **何时使用**：当有一个首要假设占据绝对优势时；需确保没有遗漏决定性替代假设时；掌握大量数据需生成与数据一致的合理假设时。
- **适合的问题类型**：涉及多个变量的复杂情报问题，特别是分析结果高度不确定时。
- **团队还是个人**：团队方法，但也可个人使用。
- **预期产出**：一份经过系统排列、按可信度排序的假设清单。

## 对抗的认知偏见 / 核心价值
- **证实偏见**：通过分解首选假设、强制质疑每个组成部分的假定，打破对首选假设的过度依附。
- **假设空间狭窄**：排列组合机制强行扩展假设空间，发现被忽略的"第四/第五种"可能性。
- 核心价值：把波普尔证伪哲学转化为可操作的假设生成工具。

## 与其他方法的关系
生成的假设可作为 **4.5 ACH** 的直接输入；与 **4.3 象限假设生成法** 同属系统生成替代解释的家族，但切入点不同——本方法从分解首选假设入手，象限法从识别关键驱动力入手。

## Anti-patterns / 潜在缺陷
- 仅适用于可由 6W 分解的问题。
- 组成部分过多 → 排列指数级爆炸，分析失控。通常 3 部分、每部分 3 替代项即可。

## Key Takeaways
- 分解首选假设为 6W
- 每维生成替代项
- 全排列后过滤无意义项
- 1–5 分可信度排序
- 通常 3×3×3 即足够

## Connects To
- **4.5 ACH**：排列产出的假设清单直接喂入 ACH 矩阵。
- **4.3 象限假设生成法**：姊妹方法，切入点不同（分解 vs 驱动力）。
- **波普尔证伪主义**：通过质疑隐含假定实现证伪精神。
