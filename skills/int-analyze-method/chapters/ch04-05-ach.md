# 4.5 — 竞争性假设分析法（Analysis of Competing Hypotheses, ACH）

**范式归属**：范式 Ⅲ：认知心理学/证伪主义范式
**方法类别**：第四类 假设生成与检验
**编号**：4.5
**★ 旗舰方法 (Flagship) — Heuer SAT 体系的标志**

**创始人/来源**：小理查兹·J·霍耶尔（Richards J. Heuer, Jr.）在中情局开发（20 世纪 80 年代中期），1999 年《情报分析心理学》首次公开发表。最初目的是分析苏联是否对美国实施欺骗行动。

## Core Idea
ACH 是整个 55 方法 SAT 体系中**最重要、最具影响力**的方法，也是情报分析从直觉判断走向系统化思维的分水岭。其思想根源是**卡尔·波普尔的科学哲学**——科学推理应从提出多种假设入手，通过**证伪**（而非证实）淘汰错误假设，暂时接受那些不能被驳倒的假设。

**ACH 的革命性在于彻底扭转了传统分析的逻辑（INVERSION 是核心）**：

- ❌ 传统（证实式）："哪一假设被这条证据支持？"
- ✅ ACH（证伪式）："哪一假设被这条证据反驳？"

最能站得住脚的假设，是**反对证据最少**的那个，而不仅仅是支持证据最多的那个。**寻求最少被驳倒的假设，而非最多被证实的假设。**

传统分析容易陷入"满意法则"——形成偏好性假设后，只去寻找支持该假设的证据，忽视或曲解矛盾信息（证实偏见典型表现）。ACH 是直接针对证实偏见设计的操作化工具。

## Framework / Mental Model
- **ACH 矩阵（The Matrix）**：假设列在上方横行，相关信息列在左列。每格标注证据与假设的关系：C（一致）/ I（不一致）/ NA（不适用）。最具说服力的证据标 Cs 或 Is。
  - When to use: 判断极为重要、不能承受出错后果时；面对争议问题需留审查线索时；需处理大量证据时；必须应对拒止与欺骗时
  - How: 9 步完整流程，矩阵是核心分析工具
- **诊断力（Diagnosticity）**：一条证据的判别能力——若它与多个假设同样一致，则无诊断价值；若它明显与某假设矛盾，则具高诊断力。**ACH 的精髓是聚焦高诊断力证据。**
- **不一致评分**：软件自动累加 I 的数量，**得分最低的假设是最可能的假设**（不是得分最高）。

## Key Concepts
- **竞争性假设**：互相排斥的多个替代解释，须排他且（理想状态下）穷尽。
- **证伪优先（Falsification First）**：寻找反驳证据，而非支持证据。
- **诊断价值 > 支持价值**：能区分假设的证据才有用。
- **缺失证据（Absent Evidence）**：如果某假设正确则应看到、却未看到的信息——同等重要。
- **假定（Assumptions）**：与事实性证据并列列入矩阵。
- **欺骗性假设**：清单应包括所有合理可能性，以及适当的欺骗假设。
- **对抗认知偏见：证实偏见（Confirmation Bias）—— THE method designed to counter confirmation bias.** 通过"反向提问"（这条证据反驳哪个假设？）操作化证伪逻辑。

## 操作步骤 (Procedure) — FULL MATRIX PROCEDURE
1. **确认要考虑的假设**。所有假设应具排他性——若某个正确，则其他都错误。清单包括所有合理可能性 + 适当的欺骗性假设。为每个假设设定简短描述情景。
2. **制定一份意义重大的"证据"清单**。包括所有相关因素：证据本身、假定、以及"如果某假设正确则应看到却缺失的信息"。假定与事实性证据同等重要。
3. **创建矩阵**。假设列上方横行，相关信息列最左列。逐格评估：该信息与假设一致吗？矛盾吗？编码 C（一致）/ I（不一致）/ NA（不适用）。特别有说服力者标 Cs / Is。
4. **回顾分析人员在评估中的分歧**，确定是否需调整评级。差异通常可回溯到分析人员赋予假设的不同假定。
5. **重新考虑假设以完善矩阵**。考虑合并假设、添加新假设，回头重新评估。
6. **给出暂定结论**。基于每条相关信息的诊断力，给出每个假设的相对可能性。**软件自动计算"不一致评分"，得分最低的假设是最可能的假设。**
7. **分析结论的敏感度**。考虑如果一项或多项关键证据是错误、欺骗性或可做不同解读，会对分析产生什么后果。
8. **报告结论**。阐明所有假设的相对可能性，不仅是最可能的那一个。说明哪些信息最具诊断力、在确认最可能假设方面有多大说服力。
9. **确定监控指标**。两份清单：①有助于证实判断的未来事件；②判断可能错误时应警惕的指标。定期验证并监控。

## Worked Example — 示意 (reconstructed from source description)
**问题**：某设施被怀疑是 X 国秘密核工厂。证据：①高安全围栏与警戒；②卫星显示疑似通风系统；③官方称是农业研究所；④周边辐射读数正常（缺失证据：未见异常辐射）；⑤进口特种钢材。

**假设 H1**：民用农业设施（官方说法）
**假设 H2**：秘密核武器工厂
**假设 H3**：生化武器设施

| 证据 \ 假设 | H1 民用 | H2 核工厂 | H3 生化 |
|---|---|---|---|
| ① 高安全围栏 | C | C | C |
| ② 疑似通风系统 | C | C | C |
| ③ 官方称农业 | C | I（说谎） | I（说谎） |
| ④ 辐射读数正常 | C | **I**（应异常） | C |
| ⑤ 进口特种钢材 | N（不适用） | Cs（强一致） | C |

**诊断力分析**：
- 证据①②无诊断价值（对所有假设均一致）。
- 证据③具中诊断力——区分说谎假设与诚实假设。
- **证据④是关键诊断证据**——核工厂应产生异常辐射，正常读数直接反驳 H2。
- 证据⑤具一定诊断力，支持 H2/H3。

**不一致评分**（I 数量）：H1=0, H2=2, H3=1。

**暂定结论**：H1（民用）最不可能被反驳，但需进一步核查证据④（是否测量可靠？是否被欺骗？）。**注意 ACH 的反直觉结论**：表面上 H2 最符合"特种钢材+通风系统"，但缺失的异常辐射证据构成了强反驳。这正是 ACH 揭示证伪逻辑威力的典型场景。

**敏感度分析**：若证据④被证明是欺骗性的（对手故意控制辐射读数），H2 的可能性显著上升。

## 适用场景 (When to Use)
- **何时使用**：判断极为重要、不能承受出错后果时；心里感觉"不太对"想用系统化方法防止意外时；面对争议问题需明确分歧并留下审查线索时；需处理大量数据（如 CBRN 技术问题）；必须应对拒止和欺骗时。
- **适合的问题类型**：对已发生、正在发生或可能发生的事情的替代解释进行系统分析；涉及大量证据需要梳理评估的复杂情报问题。
- **团队还是个人**：个人可用，但**小型团队使用最为有效**。需有经验的分析人员或培训师指导，尤其首次使用时。
- **预期产出**：一份完整 ACH 矩阵、经过系统评估的假设排序名单、附有诊断力最强的证据清单和未来监控指标清单。

## 对抗的认知偏见 / 核心价值
- **证实偏见（Confirmation Bias）—— 直接且操作化地对抗**。THE method designed to counter confirmation bias.
  - **证伪逻辑的运作机制**：传统分析问"这条证据支持我偏好的假设吗？"——这是证实式提问，几乎总会得到肯定答案。ACH 强制反向提问："这条证据反驳哪个假设？"——这是证伪式提问，迫使分析人员关注被驳斥的假设，而非被支持的假设。
  - **波普尔证伪主义的不对称性**：无论多少白天鹅都无法证实"所有天鹅都是白色"，但一只黑天鹅即可证伪。同样，无论多少支持证据都无法证实假设，但一条矛盾证据即可驳倒。ACH 利用这一不对称性，把分析精力集中在高诊断力的"证伪"操作上。
  - **Kahneman 的研究**：人类心智天然倾向证实——我们寻找支持而非反驳。ACH 用矩阵和反向提问把这一偏见外化为可见、可审计的结构。
- 核心价值：把波普尔哲学和 Kahneman 认知科学转化为可操作、可教学、可审计的工作流程。

## 与其他方法的关系
**ACH 是本书方法体系的核心枢纽**。与多个方法紧密配合：**结构化头脑风暴、名义团体法、4.2 多种假设生成程序法™、德尔菲法** 可用于识别纳入 ACH 的假设或信息；**4.7 欺骗识别法** 识别对手欺骗动机/时机/手段，相关信息纳入矩阵；**4.4 诊断推理法** 可嵌入 ACH 的评估过程；**关键假定检查法** 确定的假定作为"证据"列入矩阵；**德尔菲法** 可用于印证 ACH 结论；ACH 最后一步与 **指标验证因子法™** 衔接，确定未来监控指标。

## Anti-patterns / 潜在缺陷
- **时间密集（Time-intensive）**：完整 9 步流程耗时，不适合琐碎判断。
- **需谨慎处理证据独立性**：若多条"证据"实际来自同一来源或同一假定，累加 I 会产生虚假确定性。
- **假设须互相排斥且尽量穷尽（MECE）**：若假设重叠或遗漏关键可能性，矩阵结论无效。
- **ACH 像对抗证实偏见的"流感疫苗"——注射疫苗可免于感冒，但若已患病则无济于事。** 若分析人员早已锁定答案，会不自觉地把信息解读为与既有想法一致。
- **"不一致评分"不是神奇公式**：计算机只完成累加计算，判断准确性取决于分析人员选择的信息和评级。
- 证伪往往比证实更困难，ACH 可能**增加而非减少**分析人员对结论的不确定程度——但这种不确定性本身就是真实情形的准确反映。
- 5 种特殊情况可能导致"不一致评分"与自身判断产生矛盾：被忽视的假定/逻辑演绎、对不太可能假设关注度不够、具决定作用的关键信息、证据量失衡、回报减弱效应。

## Key Takeaways
- 反转提问：反驳哪个，而非支持哪个
- 寻求最少被驳倒，而非最多被支持
- 矩阵：假设横行、证据纵列、C/I/NA
- 诊断力 > 支持力
- 缺失证据同等重要
- 不一致评分最低者最可能
- 9 步流程，旗舰工具

- **Kahneman 的证实偏见研究**：ACH 是把 Kahneman 描述的认知缺陷外化为可审计结构的核心工具。
