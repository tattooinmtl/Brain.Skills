# 1.8 — 矩阵法（Matrices）

**范式归属**：范式 Ⅱ：量化/系统分析范式
**方法类别**：第一类 分解与可视化
**编号**：1.8

## Core Idea
矩阵是通过行和列的二维栅格组织数据的工具，让分析员能高效处理远超工作记忆容量的信息。问题被分解为单元格，每个单元格可单独分析，同时整体背景保持完整。关键限制：信息只能按**两个维度**组织——三维以上问题需组合多个矩阵。

## Framework / Mental Model
- **二维栅格模型（2D Grid Model）**：行 × 列 = 可单独分析的单元格集合
  - When to use: 需分析任意两组变量之间关系，或同一组变量相互影响时；处理大量数据应首选考虑
  - How: 确定两组待比较数据→顶行列第一组类别→最左列第二组→单元格填数据
- **五种用途**：比较不同类型/相同类型信息、按类型分类、确认模式、分离问题要素
  - When to use: 根据分析目的选择
  - How: 同一矩阵可服务于不同目的，关键在维度选择

## Key Concepts
- **二维栅格（2D Grid）**：由行和列组成的栅格结构
- **单元格（Cell）**：行与列交叉处，可单独分析的最小单位
- **竞争性假设分析法**：使用矩阵分析信息与假设的关系
- **决策矩阵**：分析目的与选项的关系
- **交叉影响矩阵**：分析变量间相互影响
- **甘特图**：使用矩阵分析任务与时间的关系

## 操作步骤 (Procedure)
1. 确定两组需要进行比较的数据资料。所有矩阵的共同点是：有足够多的行和列组成栅格，供在其中输入希望进行比较的两组数据。
2. 按一定的逻辑顺序组织并在顶行输入第一组数据资料的类别标题。
3. 在最左侧的列中输入第二组数据资料的标题。
4. 在每个单元格中加入数据资料。
5. 矩阵可用于多种目的：对不同类型的信息进行比较；对相同类型的不同信息进行比较；按类型对信息进行分类；确认信息中蕴含的模式；将一个问题的各要素分离开来。

## Worked Example
**示意**：评估 5 个备选政策选项（A-E）对 4 个评价标准（成本、效率、政治可行性、时效性）的满足程度。顶行列 A-E，最左列 4 标准，单元格填 1-10 分。横看每行可发现哪个选项在该标准上最强；竖看每列可发现该选项的强弱项分布——这是决策矩阵法的典型布局。

## 适用场景 (When to Use)
- **何时使用**: 需要分析任意两组变量之间的关系，或同一组变量之间的相互影响时；处理大量数据材料时应首先考虑使用矩阵
- **适合的问题类型**: 竞争性假设分析、交叉影响分析、决策分析、影响分析、排序与评分、甘特图规划等
- **团队还是个人**: 个人或团队均可
- **预期产出**: 以行和列组织的二维数据栅格，直观呈现变量之间的关系、模式或比较结果

## 对抗的认知偏见 / 核心价值
作为范式 Ⅱ 量化方法，矩阵对抗的核心偏见是**工作记忆过载**——分析员瞬时记忆只能同时处理约 7±2 个信息单元，超过此规模的信息处理必然导致遗漏或主观偏差。矩阵通过将信息外化为二维结构，让大脑专注于分析单元格内的关系而非记忆数据。它还对抗**隐式比较**：当比较在脑海中进行时，标准往往漂移，矩阵强制标准显性化。

## 与其他方法的关系
矩阵法贯穿本书多种方法：竞争性假设分析法使用矩阵分析信息与假设的关系；交叉影响矩阵法分析变量间相互影响；决策矩阵法分析目的与选项的关系；甘特图使用矩阵分析任务与时间的关系；加权排序法使用矩阵分析各项与评判标准的关系。

## Anti-patterns / 潜在缺陷
- **二维局限**：矩阵只能按两个维度组织信息，对于需要三个或更多维度的复杂问题，可能需要组合使用多个矩阵或采用其他方法——这是矩阵的根本性局限，不是工具选择问题
- **维度选择失当**：即便问题适合矩阵，若行/列维度选择不当，矩阵会呈现误导性模式

## Key Takeaways
1. 矩阵让大脑专注关系分析而非数据记忆
2. 严格二维——三维以上问题拆为多矩阵
3. 顶行列第一组，最左列第二组
4. 单元格是独立分析单元，整体背景保持完整
5. 矩阵是结构化分析最通用的结构单元
