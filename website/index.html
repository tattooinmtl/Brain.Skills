What it does

Two installers, one system. The brain watches and remembers; the skills hub keeps every agent equipped.

🧠3D neural view

Every conversation, tool call, sub-agent, skill and note is a node. Nodes pulse and light travels along the links while your agents work. Zoom out to see everything, fly through it, and click any node.

🔎Shared memory

Reads Claude Code (including sub-agents), Codex and any agent that writes to its event log. One searchable history of what was done, where, and with which tools.

🤝Claude can use it

Ships an MCP server and a Claude Code plugin. Claude can search past sessions before starting work and record what it learned when it's done. Other MCP clients work the same way.

📚Wiki & Librarian

Your Obsidian-style vault with a reader and editor. The Verifier Librarian flags notes that changed without review and broken [[links]]; you approve or roll back.

⚡Skills Installer Hub

Installs 230+ skills and links them into Claude Code, Codex, Gemini, Grok, Kimi, MiniMax, Omni and more. One update reaches every agent. Agents' own skills folders are never overwritten.

🔄Updates itself

The tray checks GitHub and tells you when a new version is out. Updates download only the files that changed and verify each one. Your notes are never touched.

Install

Install the Brain first, then the Skills Hub. Both always fetch the newest version from GitHub, and both install into %USERPROFILE%\.brain-skills without administrator rights.

🪟 Windows installer

Download and double-click. A console window shows progress and closes when you press Enter.

How to use it

Everything runs locally on http://127.0.0.1:6789; nothing leaves your PC.

Open the brain

Double-click the brain icon in the system tray (or the Brain.Skills Start-menu item). Right-click the icon for the wiki, the Librarian, your vault folder, updates and autostart.

Explore in 3D

  • Drag to rotate, right-drag to pan, wheel zooms toward the cursor. Zoom out as far as you like.
  • Click a node to open its panel; double-click to fly to it. / searches.
  • F starts free flight: WASD to move, Space/C up and down, Shift to boost, Esc to exit.
  • Click the legend to show or hide categories. Live conversations keep pulsing.

Inspect and edit

A node's panel shows its details: a conversation's tools, skills, sub-agents and recent calls; a skill's usage across sessions; a note's text. Edit renames it, recolours it, adds a note, edits the markdown file, or appends to its entry log.

Let Claude use it

Restart Claude Code after installing. Claude gets brain_search, brain_recent, brain_node, brain_status, brain_add_entry and brain_save_note, and the global-brain skill tells it when to look things up and when to write back. Any MCP client can run brain-system.exe --mcp.

Keep your vault clean

The Verifier Librarian tab lists Gold notes that changed without review and links with an obvious fix. Approve to accept, reject to restore the verified version (the rejected text is archived, never lost).

Stay up to date

When the tray says Update available, right-click → Update, or click the green badge in the web page. Skills update from the tray too, or run Skills Installer Hub from the Start menu.
